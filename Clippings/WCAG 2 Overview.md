> [!abstract] 摘要
> WCAG 2 规定如何让 Web 内容更易于残障人士使用。要求按可感知、可操作、可理解、健壮四项原则组织，并通过 A、AA、AAA 三个等级的可测试成功准则判断符合性。

[阅读 W3C 官方概览](https://www.w3.org/WAI/standards-guidelines/wcag/)

## 核心内容

- WCAG 适用于文本、图像、声音、代码、动态内容、多媒体、移动 Web 和 AI Web 界面。
- WCAG 2.2 包含 13 条指南；成功准则决定实际符合性。
- 2.0、2.1、2.2 都是现有标准，后续版本增加准则并保持向后兼容；W3C 推荐使用最新版本。
- 实施时还需使用 Quick Reference、Understanding、Techniques 和测试规则等配套资料。

## 适合什么时候回看

- 设计、开发或评审 Web 界面的键盘操作、语义结构、颜色、媒体和辅助技术支持时。

## 适用边界

- 本页是概览，不是完整检查清单；合规应按目标版本、地区法规、成功准则和实际测试方法确认。
