# DailyVault

DailyVault 是一个日期优先的个人记录库。每天只写一份 `YYYY/YYYY-MM-DD.md`；文章、工具、想法、行动、结果和生活片段都以当天的语境记录。Dataview 再从这些每日页面生成统计与周期复盘。

## 日常目录

```text
2026/              # 某年的记录与周期计划/复盘
├── 2026-08-17.md  # 唯一日常记录源
├── Weekly/         # 周计划与复盘（如 2026-W34.md）
├── Monthly/        # 月计划与复盘（如 2026-08.md）
├── Quarterly/      # 季计划与复盘（如 2026-Q3.md）
└── Yearly/         # 年计划与复盘 + 年度统计（如 2026.md、2026 统计.md）
Clippings/          # Web Clipper 原文快照
Templates/          # 每日、周期和年度统计模板
```

本地 HTTP/MCP 支持代码位于隐藏目录 `.dailyvault/openapi/`，与 Obsidian 内容层分开；其 OpenAPI 契约也保留在该目录中。

## 每天怎么写

1. 用 QuickAdd 创建 `YYYY/YYYY-MM-DD.md`（自动落到当年目录）。
2. 今日计划最多写三项；白天的临时内容都追加到“随手记录”。
3. 文章、工具、课程和反馈写在“输入”；实际结果写在“输出”；生活经历写在“生活时间线”。
4. 晚上补“学到”“复盘”和“明日 / 迁移”。空白可以留空。

```markdown
## 输入
- 读了 [[Clippings/在花大钱之前，先花一笔小钱验证你的决策]]，其中的小成本验证思路值得尝试。
- 发现了 [某个任务工具](https://example.com)，准备在本周试用。

## 输出
- 用新工具整理了本周任务。

## 学到
- 先验证使用场景，再投入迁移成本。
```

同一件事不必重复记录：接触到一篇文章是输入；它带来的个人认识才是“学到”；实际产出才是“输出”。

## 分类标识

固定章节提供一级分类。需要在 Dataview 中按类型统计的条目，再在行尾添加一个 `#kind/...` 标签：

```markdown
- 读了某篇文章 #kind/article
- 发现了一个任务工具 #kind/tool
- 看了一部电影 #kind/movie
- 练了 30 分钟力量 #kind/fitness
```

常用类型只有：`article`、`tool`、`course`、`book`、`video`、`podcast`、`movie`、`music`、`place`、`fitness`、`decision`、`project`。主题需要长期追踪时，才额外添加 `#topic/...`；不要为每条记录补一组字段。

## Clippings

Obsidian Web Clipper 直接写入 `Clippings/`。需要在每日记录中提及时，添加一个可读链接和当天的判断；不要为剪藏再创建第二份资料记录。

## 周期计划与复盘（一期一文件）

每个周期一个文件，同时承载计划与复盘，与每日页面的「今日计划 → 复盘」同构：

- **期初**：QuickAdd「创建周/月/季/年计划与复盘」创建 `2026-W34.md` / `2026-08.md` / `2026-Q3.md` / `2026.md`，先填「本期计划」（≤3 项）。
- **期内**：把本期计划拆解到各天的「今日计划」，计划文件不需要重复维护。
- **期末**：在同一文件补「本期总结」与「下期重点」（即下一期计划）。

周期文件只保留叙事（本期计划 / 本期总结 / 下期重点），统计不内嵌——周/月/季模板只带一行指向年度统计的外链（如 `[[2026 统计]]`）。

**年度统计**是唯一预置的统计（`YYYY/Yearly/{YYYY} 统计.md`，`note_type: stats`，创建年度文件时由 Templater 自动生成），用自身的 `year` frontmatter 匹配每日页面（`note_type: daily-log`），只做全年一次：

- 页面覆盖和日期属性（章节条目统计、每日活跃度）；
- 计划完成情况与未完成任务；
- `#kind/...` 条目分类；
- 剪藏输入（按 `Clippings/` 的 `created` 字段归集）。

周期粒度的统计不单独建文件——要看某月/某周的数字，翻每日记录或由复盘摘录。这让每日记录保持人可读，周期文件保持聚焦，统计只在年度做一个全局视角。
