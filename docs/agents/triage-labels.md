# 分流标签

这些技能使用五个标准分流角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| `mattpocock/skills` 中的标签 | 本仓库标签        | 含义                         |
| ---------------------------- | ----------------- | ---------------------------- |
| `needs-triage`               | `needs-triage`    | 需要维护者评估该 issue       |
| `needs-info`                 | `needs-info`      | 等待报告者补充信息           |
| `ready-for-agent`            | `ready-for-agent` | 规格完整，可交由 AFK agent   |
| `ready-for-human`            | `ready-for-human` | 需要人工实现                 |
| `wontfix`                    | `wontfix`         | 不会处理                     |

当技能提到某个角色时，例如“应用适合 AFK agent 的标签”，使用本表对应的标签字符串。

如果 tracker 已采用其他词汇，可修改右侧“本仓库标签”列。
