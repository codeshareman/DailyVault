# 长期收入机会清单：方式 × 人物画像

依据：[[长期赚钱方式：价值留存与选择权]] · 参照：[[中期赚钱方式：持续收入与有效积累]]、[[短期收入机会]]

> **这是长期机会池，不是最终筛选表。** 长期关注跨年度的价值寿命、收益权、复用、能力迁移、风险承受、委托、可转移和退出。低客单价、慢增长、尚无受众、需要多年建设或可能最终不产生收入的方向均保留；不把坚持、规模、估值、粉丝或本金增长当作已实现收益。
>
> [推断] 每行是一个待验证组合：**可留存价值／收益权 × 人物画像与付款人 × 长期问题 × 交付或收益机制**。现实机会无法被清单绝对穷尽；新想法必须能进入某个价值机制，否则补入新编号。所有资格、权利、税费、平台、隐私、保险和消费者保护要求仍须逐项核验。

## 阅读与入池规则

- 不按客单价、当前能力、规模、增长速度、可复制性、已有受众或是否已盈利筛选。
- 区分：劳动收入、经营利润、许可费、佣金、股息、利息、租金、资本利得、赞助、补贴、赠与和本金回收。
- “长期”不是经营超过六个月；它要求考察跨年度变化：旧成果是否仍有用、下一笔收入为何发生、风险是否集中、本人能否转向或退出。
- 有价值但暂时没有收入的作品、能力、关系和公共成果可保留为长期候选，但不能记为收入。
- 需要长期建设的机会不提前排除；需要许可的机会保留为“条件待核”，取得许可前不执行。
- 每个机会单独验证：价值寿命、收益权、复用机制、需求变化、替代风险、控制权、长期成本、生活适配与退出路径。

## 长期价值机制

| 机制 | 长期留下什么 | 典型收益来源 |
|---|---|---|
| L1 | 职业能力与议价权 | 薪酬、奖金、顾问费、合作收入 |
| L2 | 内容、版权与作品库 | 销售、稿费、授权、赞助、分成 |
| L3 | 软件、数据与数字产品 | 许可、订阅、按量、支持、转让 |
| L4 | 专业信誉与客户关系 | 复购、转介绍、长期合同、项目费 |
| L5 | 品牌、受众与分发渠道 | 广告、合作、联盟、商品、服务 |
| L6 | 流程、团队与组织能力 | 管理费、项目利润、分包、代理 |
| L7 | 商品、供应链与实物经营 | 销售差额、复购、授权、租赁 |
| L8 | 房屋、设备、空间与使用权 | 租金、租赁费、服务费 |
| L9 | 股权、金融与收益权资产 | 股息、利息、分红、资本利得 |
| L10 | 关系、社群与网络 | 会费、活动、撮合、赞助、合作 |
| L11 | 能力迁移与选择权 | 转行、跨行业、许可、转让、退出 |
| L12 | 生活与风险缓冲 | 降低支出、减少债务、保持流动性；不等于收入 |

## A｜职业能力、专业资格与长期劳动收入

- **A01 专业技术岗位**｜企业与组织｜持续交付技术结果｜薪酬、奖金与晋升。
- **A02 技术专家路线**｜需要复杂问题解决的企业｜积累稀缺判断与案例｜更高薪酬、顾问费或项目费。
- **A03 管理路线**｜需要带团队和资源协调的组织｜交付组织结果｜薪酬、奖金或利润分成。
- **A04 销售与客户成功岗位**｜企业｜持续获得或留住客户｜底薪、提成、续费佣金。
- **A05 运营与供应链岗位**｜商户、制造商和平台｜降低成本、提高交付效率｜薪酬、绩效或管理费。
- **A06 设计与创意职业**｜品牌、产品团队和媒体｜持续原创与设计判断｜薪酬、项目费、版权或分成。
- **A07 写作、编辑与翻译职业**｜媒体、出版社和企业｜持续内容交付｜薪酬、稿费、授权。
- **A08 教学与培训职业**｜学校、机构、企业和学习者｜持续教学结果｜薪酬、课酬、课程授权。
- **A09 合规专业职业**｜个人、企业和机构｜法律、财税、医疗等许可范围服务｜长期合同、按期服务费；资格待核。
- **A10 研究与分析职业**｜企业、机构、基金和媒体｜持续研究判断｜薪酬、报告费、顾问费。
- **A11 手艺与维修职业**｜家庭、商户和机构｜持续解决实物问题｜按次、维护合同、培训。
- **A12 线下照护职业**｜家庭、机构和服务组织｜长期照护、陪伴或教育｜薪酬、服务费；资格和安全待核。
- **A13 自由职业长期合同**｜持续有内容、技术或运营需求的客户｜固定范围持续交付｜月费、项目费、续约。
- **A14 多客户顾问组合**｜多个同类企业｜重复解决同类问题｜顾问费、维护费；客户集中度待核。
- **A15 职业资格与证照积累**｜有资格门槛的行业客户｜可验证的专业资格｜薪酬、服务费或准入机会，不把证书本身当收入。
- **A16 行业人脉与合作记录**｜企业、客户和合作方｜长期信任与转介｜项目、佣金或合作收入；关系不可任意出售。
- **A17 远程与跨地域劳动**｜海外或异地雇主、客户｜远程交付能力｜薪酬、合同费；税务、支付和地区规则待核。
- **A18 职业转型**｜新行业雇主或客户｜迁移后的能力组合｜新岗位、项目或顾问收入；投入期不算收入。

## B｜原创内容、版权与作品库

- **B01 长期主题文章库**｜持续需要知识的读者、编辑和品牌｜可更新原创文章｜稿费、付费阅读、授权、赞助。
- **B02 专业 Newsletter**｜需要长期筛选信息的专业人群｜定期编辑内容｜订阅、广告、赞助、服务线索。
- **B03 视频频道**｜学习、娱乐或行业信息观众｜持续视频作品库｜平台分成、品牌合作、赞助、商品或服务。
- **B04 播客节目**｜兴趣与行业听众｜长期节目与档案｜广告、赞助、会员、活动或授权。
- **B05 电子书系列**｜围绕长期主题的读者｜多卷原创内容｜销售、稿费、授权。
- **B06 教程与案例库**｜学习者、从业者和企业｜持续更新教程｜销售、企业培训、授权。
- **B07 影像作品库**｜媒体、品牌、家庭和机构｜照片、视频或音频作品｜销售、许可、委托、展览合作。
- **B08 插画、字体与视觉资产库**｜设计师、品牌和出版方｜可重复授权作品｜许可、定制和合作。
- **B09 音乐、音效与配音库**｜视频、游戏、广告和课程团队｜可重复使用的音频｜许可、版税、委托。
- **B10 研究报告与方法论库**｜企业、研究者和机构｜有来源的原创研究｜报告销售、订阅、咨询、授权。
- **B11 公开内容＋付费深度内容**｜先免费了解、再解决深层问题的读者｜分层内容｜按篇、订阅或授权；免费流量不等于付费。
- **B12 内容会员**｜需要持续内容或互动的读者｜定期内容和权益｜会员费；承诺、取消和维护待核。
- **B13 读者赞助**｜愿意支持长期创作的读者｜持续公开作品｜赞助或打赏；自愿支持不保证稳定。
- **B14 内容平台分成**｜平台｜持续发布合规内容｜实际分成；播放、粉丝和到账分开。
- **B15 品牌长期内容合作**｜需要特定受众的品牌｜连续内容或栏目｜合同费、赞助、授权；广告关系披露。
- **B16 作品集与创作者品牌**｜客户、编辑、品牌和合作方｜可验证作品与风格｜委托、授权、合作；作品热度不保证订单。
- **B17 公共知识与开源内容**｜用户、企业、赞助方｜持续公开维护｜赞助、服务、培训、授权；免费使用不等于收入。
- **B18 翻译与本地化内容库**｜持续跨语言发布的企业｜术语和译稿资产｜合同、按字、维护费；权利与保密待核。
- **B19 长期内容 IP**｜读者、品牌、出版与授权方｜角色、主题、故事或方法体系｜出版、改编、授权、商品、合作；多年需求待验证。
- **B20 作品版权转让或出售**｜出版商、媒体、品牌或收购方｜明确可转移的版权｜一次性款或分成；转让范围不可含糊。

## C｜软件、工具、数据与数字产品资产

- **C01 微型 SaaS**｜有单一重复问题的用户和小团队｜长期可用的软件价值｜订阅、按量、许可。
- **C02 企业软件服务**｜企业客户｜流程、权限和持续支持｜年度合同、席位费、实施费。
- **C03 开源项目商业支持**｜使用项目的团队｜维护、部署、培训和支持｜赞助、服务费、支持合同。
- **C04 插件与扩展生态**｜开发者、设计师和业务用户｜兼容性、功能与社区｜许可、订阅、支持、赞助。
- **C05 API 与数据服务**｜需要机器可读结果的开发者和企业｜持续接口或数据供给｜按量、订阅、企业合同。
- **C06 数据库与目录产品**｜研究、采购、销售和内容团队｜合法、持续更新的数据｜订阅、许可、报告。
- **C07 工作流模板产品线**｜个人、团队和企业｜多场景模板与更新｜按份、包、会员、企业授权。
- **C08 企业知识库产品**｜组织和团队｜可迁移的结构、权限和内容｜项目费、许可、维护。
- **C09 自动化工具链**｜运营、行政、创作者和开发者｜可复用自动化｜许可、订阅、实施、维护。
- **C10 AI 应用与代理服务**｜需要持续自动化的个人和企业｜有边界的模型调用与工作流｜订阅、按量、实施、支持；模型、数据和成本依赖待核。
- **C11 AI 内容生产工具**｜商户、品牌和创作者｜稳定生成、审核和资产管理｜订阅、按量、授权。
- **C12 设计系统与组件库**｜产品团队和开发者｜长期复用的组件与规范｜许可、企业授权、实施、维护。
- **C13 数字下载商店**｜持续出现窄问题的买方｜大量低价原创数字品｜按份、组合、订阅；低客单价不排除。
- **C14 数字产品更新订阅**｜需要持续版本的用户｜更新、兼容和支持｜订阅；不以永久更新换一次性收费。
- **C15 插件／软件项目出售**｜项目收购方｜可转移的代码、品牌和用户权益｜一次性出售或分成；第三方许可与数据另核。
- **C16 域名与网站资产经营**｜品牌、项目方和收购者｜权属清楚的域名、网站或流量入口｜出售、租赁、广告、服务；侵权抢注排除。
- **C17 数字内容许可库**｜媒体、企业和教育团队｜可检索且权利清晰的内容｜按期、按用量、按授权。
- **C18 数字产品白标／联营**｜需要自有品牌工具的服务商｜授权产品和交付能力｜许可、分成、实施；责任边界明确。
- **C19 数据标注与评测组织**｜模型、数据和研究项目方｜稳定合规的执行网络｜项目费、管理费、按验收；不把个人数据当资产。
- **C20 软件托管与运维平台**｜没有基础设施能力的团队｜可靠运行环境与支持｜订阅、按量、企业合同。

## D｜专业服务、客户资产与长期合同

- **D01 固定范围顾问服务**｜反复遇到相近问题的企业｜经验、方法、案例和流程｜月费、小时包、项目。
- **D02 技术诊断与维护合同**｜网站、软件和设备客户｜周期检查、修复和升级｜月费、维护包。
- **D03 设计与内容维护合同**｜品牌、门店和媒体｜持续视觉与内容交付｜月费、按包。
- **D04 电商运营合同**｜网店与品牌｜上架、客服、活动、数据和售后｜月费、项目费、绩效；绩效定义待核。
- **D05 企业行政外包**｜小企业和自由职业者｜日程、资料、招聘和流程｜月费、小时包。
- **D06 销售与线索服务**｜有产品但缺销售能力的企业｜真实线索、邀约和跟进｜服务费、合格线索费、佣金；隐私和归因待核。
- **D07 客户成功与续费服务**｜软件和服务供应商｜使用跟进、培训和留存｜月费、续费佣金。
- **D08 合规代理／经销**｜软件、工具、商品供给方｜销售、实施与客户转接｜差价、佣金、续费；不共享账户。
- **D09 供应商采购服务**｜小商户和企业｜持续比价、采购与供给管理｜管理费、采购服务费；返佣披露。
- **D10 研究与战略咨询**｜企业、品牌和机构｜持续研究、决策材料和复盘｜项目费、顾问费、长期合同。
- **D11 人力与人才推荐**｜企业、候选人或人才机构｜合规匹配与入职服务｜服务费、佣金；资质与个人信息待核。
- **D12 房源、空间与设备经纪**｜资产所有者和使用者｜长期匹配与管理｜佣金、管理费；行业规则待核。
- **D13 受托运营客户资产**｜没有时间经营的资产所有者｜授权经营、展示和维护｜管理费、分成；所有权与责任分开。
- **D14 专业许可服务事务所**｜企业、家庭和机构｜会计、法律、医疗等服务｜按期、按事项、合同；资格必须满足。
- **D15 课程与培训机构**｜学习者和企业｜重复开课、材料和认证支持｜学费、企业合同、授权。
- **D16 照护与家庭服务机构**｜家庭与照护对象｜排班、人员和服务标准｜服务费、管理费；安全和许可待核。
- **D17 本地生活服务网络**｜居民、商户和服务者｜标准化匹配、排班和质量｜服务费、佣金、会员；投诉与保险待核。
- **D18 维修、安装与售后网络**｜家庭、门店和品牌｜标准化服务与备件｜按次、维护合同、品牌授权。
- **D19 内容制作工作室**｜品牌、媒体和创作者｜持续脚本、拍摄、剪辑和发布素材｜月费、项目费。
- **D20 分包与协作交付工作室**｜需要多技能交付的客户｜组织合作者完成项目｜项目费、管理费；质量和付款责任明确。
- **D21 远程客服与社群运营**｜软件、课程、品牌和社区｜固定时段工单、社群与用户支持｜月费、按工单。
- **D22 个人品牌商务代理**｜创作者、专家和品牌｜合作谈判与交付管理｜服务费、佣金；授权和商业披露待核。
- **D23 长期项目管理**｜建设、技术、活动和内容项目方｜持续协调、风险和交付｜项目费、管理费；不承诺无限责任。
- **D24 多客户知识服务**｜同类企业与专业用户｜共享研究、答疑和判断资产｜会员、顾问费、授权；客户数据隔离。

## E｜品牌、受众、社区与交易网络

- **E01 垂直媒体品牌**｜特定主题读者与品牌｜持续内容与受众关系｜广告、赞助、产品、服务、授权。
- **E02 专业个人品牌**｜需要可信专家的客户与受众｜作品、观点和案例｜咨询、培训、委托、授权。
- **E03 本地生活品牌**｜附近居民和商户｜可信信息、服务和活动｜广告、线索、会员、服务费。
- **E04 兴趣社群**｜同好与学习者｜持续交流、内容和活动｜会员费、活动费、赞助、商品。
- **E05 专业会员网络**｜行业从业者和企业｜资源、研究、招聘和合作｜会费、赞助、招聘、活动。
- **E06 创作者社群**｜创作者、品牌和服务商｜合作、工具和资源连接｜会费、活动、佣金、赞助。
- **E07 开源社区**｜开发者、企业和赞助者｜项目、文档、贡献者与信任｜赞助、服务、培训、许可。
- **E08 联盟导购渠道**｜有购买问题的受众与官方联盟商｜真实比较与推荐｜合格成交佣金；披露和退单待核。
- **E09 销售线索渠道**｜需要客户的服务商｜经授权的合格线索｜线索费、佣金；不买卖隐私数据。
- **E10 供需撮合平台**｜买方与供给方｜搜索、匹配、评价和交易流程｜服务费、佣金、订阅；平台责任待核。
- **E11 二手交易网络**｜卖方、买方和寄售者｜垂直品类信任、验货和流转｜差价、寄售佣金、服务费。
- **E12 专业人才网络**｜企业与候选人｜合规筛选和匹配｜招聘费、佣金；许可与隐私待核。
- **E13 活动与课程网络**｜讲师、学习者、场地方｜持续活动与报名入口｜报名费、场地费、赞助、佣金。
- **E14 众筹、预售与支持社区**｜支持者、创作者和项目方｜资金、反馈与早期关系｜预售、会员、赞助；预收款对应交付责任。
- **E15 品牌联名网络**｜品牌、创作者与消费者｜共同作品、商品或活动｜授权费、销售分成、合作费。
- **E16 代理与经销渠道**｜供给方和终端买方｜长期销售与售后转接｜差价、佣金、续费；控制权集中待核。
- **E17 社群团购与采购网络**｜消费者与供给商｜持续真实需求汇总｜组织费、佣金；不虚构销量。
- **E18 读者／用户转介绍网络**｜已有客户与新客户｜可信推荐和归因｜佣金、服务费；用户关系不能任意转让。
- **E19 媒体分发与内容授权网络**｜作者、媒体、品牌和读者｜内容分发与权利管理｜稿费、授权、分成。
- **E20 平台生态服务**｜平台商户、开发者和用户｜插件、模板、实施和支持｜许可、服务、平台分成；平台依赖待核。

## F｜商品、品牌、供应链与实体经营

- **F01 长期复购日用品**｜家庭和小商户｜稳定消耗品供应｜按件、订阅、批量合同。
- **F02 宠物用品与服务品牌**｜宠物主人｜商品、照护和内容｜销售、订阅、服务费。
- **F03 植物、花卉与园艺品牌**｜家庭、办公室和活动方｜商品与维护服务｜销售、维护包、活动合作。
- **F04 食品与烘焙品牌**｜家庭、活动方和门店｜合规食品与预订｜销售、预订、批量合同；许可待核。
- **F05 企业礼品与定制品牌**｜企业、活动和送礼者｜稳定规格的定制品｜按批、长期采购合同。
- **F06 手作与设计商品品牌**｜特定审美和用途的消费者｜作品、故事和商品｜销售、联名、授权。
- **F07 按需印刷与小批量制造**｜创作者、社群和小商户｜设计与供应链交付｜按件、预售、批量。
- **F08 二手垂直品类经营**｜买方与卖方｜验货、翻新、库存与信任｜差价、寄售、服务费。
- **F09 维修翻新品牌**｜低预算设备和家具买家｜检修、翻新和售后｜销售差额、维修费、维护合同。
- **F10 服装、道具与设备租赁品牌**｜活动、拍摄和临时使用者｜循环利用资产｜租赁费、配送、维护。
- **F11 设备与工具租赁**｜个人、商户和活动方｜重复出租的设备｜按天、会员、企业合同。
- **F12 车位、储物和场地经营**｜附近使用者、活动方和商户｜空间使用权｜租金、管理费、服务费。
- **F13 合规住宿经营**｜出差、旅游和过渡居住者｜长期住宿服务｜租金、住宿费；产权、租约和当地规则待核。
- **F14 小型零售店**｜社区或垂直兴趣消费者｜选品、库存和服务｜销售差额、会员、供应商合作。
- **F15 社区配送与订阅**｜固定区域家庭和商户｜周期配送路线｜配送费、订阅、商户合同。
- **F16 供应链服务商**｜商户和品牌｜采购、仓储、包装和履约｜服务费、合同、差价。
- **F17 物业与资产维护**｜房东、机构和商户｜长期保洁、维修和检查｜维护费、管理合同。
- **F18 线下门店品牌**｜本地消费者｜重复消费体验｜商品、服务、会员；营业额不等于利润。
- **F19 特许经营或品牌授权**｜品牌方与经营者｜标准化品牌和经营系统｜授权费、管理费、销售分成；合同待核。
- **F20 联营商品品牌**｜品牌、创作者与制造方｜共同设计与分销｜销售分成、授权、批发。

**G 与 K 的区别：** G 记录资产、股权、金融工具、租赁物和收益权本身可能产生的长期回报；K 记录收到的现金是否其实是退款、补偿、赠与、融资、本金或未实现估值。G 关注“资产能产生什么”，K 关注“这笔现金应如何定性”；两处不重复记录同一事实。
## G｜金融、股权、资产与收益权安排

- **G01 现金与应急储备管理**｜自己或家庭｜流动性与风险缓冲｜减少利息和损失，不是新增收入。
- **G02 存款与货币市场工具**｜银行或发行方｜资金使用权｜利息；本金与收益分开。
- **G03 债券与固定收益资产**｜发行方与市场买方｜利息或到期偿还｜利息、到期款；信用、期限与利率风险待核。
- **G04 股息型股权投资**｜企业或基金｜合法收益权｜股息、分红；不保证分配。
- **G05 指数与分散化投资**｜基金、市场和发行方｜组合资产收益权｜分配与资本利得；不保证盈利。
- **G06 价值投资**｜上市或非上市资产｜研究后的所有权收益权｜股息、分红、资本利得；估值可能错误。
- **G07 资产配置与再平衡**｜多个资产类别｜风险、期限与流动性组合｜收益与风险控制；不是独立收入来源。
- **G08 房地产租金收益**｜承租人｜房屋使用权｜租金；空置、维修、税费和物业责任待核。
- **G09 车位、仓储与场地收益**｜使用者｜空间使用权｜租金、管理费。
- **G10 设备租赁收益**｜临时使用者｜设备使用权｜租金；折旧、损坏和利用率待核。
- **G11 知识产权许可收益**｜被许可方｜内容、软件、设计或品牌使用权｜许可费、版税、分成。
- **G12 股权或合伙收益**｜公司、合伙企业｜经营份额与分配权｜分红、利润分配、退出收益；流动性和控制权待核。
- **G13 员工股权、期权或长期激励**｜雇主｜合同约定的权益｜归属、分红或退出收益；不把未归属估值当收入。
- **G14 小企业部分所有权**｜经营者或投资人｜合法经营份额｜利润分配、出售份额；尽调与控制权待核。
- **G15 特许经营投资**｜品牌方与消费者｜品牌和经营权｜经营利润、分成；投入和合同风险待核。
- **G16 基础设施或项目收益权**｜项目方与使用者｜合法项目份额｜分配、租金或服务费；监管和流动性待核。
- **G17 收藏品与贵金属资产**｜市场买方｜实物资产处分权｜出售差额；真伪、保管和流动性待核。
- **G18 域名、网站和数字资产所有权**｜收购方、租户或广告主｜合法可转移资产｜出售、租赁、广告、服务；估值不等于到账。
- **G19 资产证券化或基金份额**｜发行方与市场｜合法份额收益权｜分配与变现；产品规则和损失风险待核。
- **G20 可转让合同收益权**｜受让方或合同相对方｜合同允许的收益或权利转让｜转让款、分成；合同、税费和同意要求待核。
- **G21 养老金与长期保障安排**｜个人、雇主或保险机构｜未来保障权益｜未来给付；不是当前收入。
- **G22 保险与风险转移安排**｜保险机构｜风险保障｜理赔是损失补偿，不当经营收入。

## H｜委托、组织化、自动化与可转移经营

- **H01 标准化交付流程**｜多次购买同类服务的客户｜流程、清单和质量标准｜提高复用与容量，不自动产生收入。
- **H02 自动化交付系统**｜需要低人工成本的客户｜软件与流程组合｜订阅、按量、实施费。
- **H03 助理与运营委托**｜已有客户或受众的经营者｜把可标准化工作交给协作者｜管理费、利润或服务容量；责任仍保留。
- **H04 分包网络**｜需要持续项目交付的客户｜组织多个专业者｜项目管理费、利润分成；质量与付款风险待核。
- **H05 内容编辑团队**｜作者、品牌和媒体｜持续内容生产与版权管理｜合同费、授权、分成。
- **H06 技术支持团队**｜软件与企业客户｜轮值支持与知识库｜月费、企业合同。
- **H07 本地服务团队**｜家庭、商户和机构｜排班、培训和质量控制｜服务费、管理费。
- **H08 销售代理团队**｜供给方｜持续销售与客户管理｜佣金、底薪、分成；授权待核。
- **H09 采购与履约团队**｜商户和品牌｜持续采购、仓配和交付｜管理费、差价、合同。
- **H10 品牌授权经营**｜被授权经营者与品牌方｜标准、商标和系统｜授权费、分成；品牌质量责任明确。
- **H11 许可证与版权管理**｜作者、企业与被许可方｜权利登记、授权和收款｜管理费、许可分成。
- **H12 客户关系可转移服务**｜企业客户｜文档化交付和团队接替｜合同费、管理费；个人依赖逐步降低。
- **H13 可出售的小型业务**｜收购方｜客户、流程、品牌、合同和资产｜出售款、分期或利润分成；不保证有买家。
- **H14 可授权的方法体系**｜企业、培训者和服务者｜原创方法、教材和标准｜许可、培训、顾问费。
- **H15 可加盟的服务体系**｜加盟经营者｜品牌、流程、培训与供应链｜加盟费、管理费、分成；合同待核。
- **H16 企业内部流程产品化**｜多个组织或部门｜重复流程与工具包｜许可、实施、维护。
- **H17 个人能力产品化**｜学习者、客户和企业｜把个人判断转为内容、工具或培训｜销售、许可、服务；不假定完全自动化。
- **H18 资产与业务退出服务**｜经营者、资产所有者｜估值、转让、交接和收尾｜顾问费、经纪费；专业资格待核。

## I｜能力迁移、选择权与退出相关机会

- **I01 跨行业技术能力**｜新行业企业｜把工程、数据或产品能力迁移到新场景｜薪酬、项目、顾问费。
- **I02 跨工具创作能力**｜品牌、媒体和客户｜载体变化后仍能交付内容｜委托、授权、合作。
- **I03 通用研究与判断能力**｜企业、研究者和机构｜在新主题中复用方法｜报告、咨询、教学。
- **I04 商业判断与定价能力**｜商户、团队和经营者｜改善产品、渠道与交易设计｜顾问费、经营利润、分成。
- **I05 组织与管理能力**｜团队和项目方｜换业务仍能组织人员、流程和资源｜薪酬、管理费、利润分成。
- **I06 教学与表达能力**｜学习者、读者和组织｜把经验迁移为解释与训练｜课程、培训、内容、咨询。
- **I07 行业关系迁移**｜新客户、合作方和雇主｜基于信任建立新连接｜项目、引荐、商务合作；关系不等于可出售资产。
- **I08 个人品牌迁移**｜新平台、新主题和合作方｜用户为何继续选择本人｜合作、授权、服务；平台迁移成本待核。
- **I09 作品版权迁移**｜媒体、品牌、出版和教育方｜改编、再版或跨媒介使用｜许可、版税、销售。
- **I10 软件架构与方法迁移**｜不同技术栈和行业客户｜抽象能力与案例｜项目、咨询、产品许可。
- **I11 可休假、转向的收入结构**｜客户、团队或资产使用者｜降低本人持续参与依赖｜维护费、授权、管理费、租金；委托成本待核。
- **I12 缩减后仍可维持的业务**｜已有客户与用户｜保留高价值、低承诺部分｜小规模收入、许可、有限服务。
- **I13 业务或作品暂停后的重新启动**｜未来客户、平台和合作方｜可保存的内容、代码、合同与关系｜重新销售、授权或复工；不把暂停期间算收入。
- **I14 有序退出与未履约处理**｜客户、用户、合作方｜完成承诺、迁移数据与关闭服务｜通常是成本与责任，不是收入；退出方案本身保留。
- **I15 第二职业与组合职业**｜多个雇主、客户或用户｜职业能力和生活安排组合｜薪酬、项目、内容、授权；时间冲突待核。
- **I16 退休后顾问或兼职**｜原行业客户和组织｜经验与时间的有限交付｜顾问费、课酬、董事或项目报酬；资格待核。
- **I17 家庭成员协作经营**｜家庭客户或企业｜分工、照护与经营能力｜经营利润、薪酬、服务费；产权和责任明确。
- **I18 生活优先的充足性方案**｜自己与家庭｜降低支出、债务和过度承诺｜可支配结余和自由时间增加，不当作收入机会。

## J｜组合路径：同一价值如何跨多年变现

- **J01 内容 → 数字产品 → 授权**｜读者、买方、企业｜从公开作品到固定成品再到许可｜分别验证阅读、购买和权利范围。
- **J02 内容 → 受众 → 品牌合作**｜读者、品牌｜持续内容与商业触达｜不把粉丝数当信任或订单。
- **J03 内容 → 课程 → 企业培训**｜学习者、企业｜同一知识的多种交付｜内容、实时教学与企业交付分别计价。
- **J04 工具 → 插件 → SaaS**｜个人用户、小团队、企业｜从单点功能到持续服务｜验证留存、支持、迁移和定价。
- **J05 开源 → 支持 → 企业合同**｜个人使用者、企业｜免费使用与商业服务分开｜许可证、服务、赞助分别验证。
- **J06 服务 → 流程 → 团队**｜客户、协作者｜从个人劳动到组织交付｜验证标准化、质量和管理成本。
- **J07 服务 → 案例 → 产品**｜同类客户｜把共性问题变成成品｜验证独立使用，不把每次定制藏在产品中。
- **J08 社群 → 活动 → 会员**｜成员、讲师、品牌｜关系、线下活动与持续权益｜验证成员留存和承诺成本。
- **J09 受众 → 联盟 → 自有商品**｜受众、合作商、买方｜推荐与自有产品并存｜披露佣金、权利和库存责任。
- **J10 二手 → 翻新 → 租赁**｜卖方、低价买方、临时使用者｜同一实物流转的多种收益｜所有权、维修和租赁责任分开。
- **J11 商品 → 安装 → 维护**｜商品买方｜销售、劳动和持续支持｜分别核算差价、服务费和维护承诺。
- **J12 资产 → 出租 → 管理**｜使用者、资产所有者｜利用率与代运营｜租金、管理费和损坏责任分开。
- **J13 个人品牌 → 代理 → 联营**｜品牌、创作者、客户｜信任、合作和商品／服务｜代理权、销售权、分成明确。
- **J14 研究 → 数据产品 → 顾问**｜研究者、企业｜信息、持续更新与判断｜数据权利和专业意见边界分开。
- **J15 职业 → 作品 → 业务**｜雇主、客户、用户｜劳动经验沉淀为可出售成果｜不把雇主所有的成果擅自商业化。
- **J16 低价产品 → 组合 → 企业授权**｜个人、小团队、企业｜低客单价入口与高价值许可｜首购、使用和授权分别验证。
- **J17 现金流 → 再投入 → 资产或能力**｜自己、客户、资产使用者｜收入支持下一阶段积累｜新增投入、收益和本金分开。
- **J18 经营 → 委托 → 转让或退出**｜客户、团队、收购方｜降低个人依赖并保留选择｜转让可能性、未履约义务与成本待核。

## K｜非收入现金流与风险边界

- **K01 退款、押金和预付款返还**｜原交易相对方｜取回自己的钱｜不是收入。
- **K02 报销**｜雇主或委托方｜真实成本补偿｜与劳动报酬分列。
- **K03 补贴、退税和基金拨款**｜主管机构、基金方｜符合条件的转移或项目资金｜按规则单列，不预估到账。
- **K04 保险理赔与合同赔付**｜保险机构、责任方｜损失补偿｜不是经营收入。
- **K05 债权与代垫款回收**｜原债务人｜收回本金或应收款｜本金回收不等于新增收入。
- **K06 赠与与家庭支持**｜家人、赠与人、资助方｜资金转移｜不等于交易收入。
- **K07 继承与遗赠**｜遗赠人、遗产管理方｜合法财产转移｜不是经营收入，手续和税费待核。
- **K08 债务减免与利息减少**｜债权人、金融机构｜减少未来支出｜改善现金流，不是收入。
- **K09 降低生活成本的资产或技能**｜自己与家庭｜自用住房、工具、维修和烹饪能力｜节省支出，不计经营收入。
- **K10 借款与融资**｜金融机构、个人或投资方｜现金使用权｜负债或资本来源，不是收入。
- **K11 资产本金变现**｜市场买方｜所有权转移｜本金、费用、税费和盈亏分开。
- **K12 账面估值增加**｜市场估值｜未实现价格变化｜不是到账收入。
- **K13 预收长期合同款**｜客户｜未来服务的提前付款｜对应履约负债，不全额当期收入。
- **K14 未归属期权、积分或奖励**｜雇主、平台、项目方｜未来可能权益｜未归属、不可提现或未结算不算收入。

## L｜条件待核与不可接受方案

- **L01 资格待核的专业服务**｜会计、税务、法律、医疗、心理、教育、驾驶、儿童照护、高风险维修等方向保留｜取得必要资格、保险和许可前不执行。
- **L02 授权待核的版权与软件许可**｜作品、代码、字体、声音、数据和模型素材｜核对权利链、地域、期限、排他性和用途。
- **L03 授权待核的分销与代理**｜AI 服务、软件许可证、商品、票券和会员权益｜具体服务商或发行方允许才执行；账户共享不是分销。
- **L04 票务和权益交易**｜普通代订、明确允许转让的票券、实名／限购受限方案分别判断｜不把“代抢”一词直接等同合法或违法，但规避规则的方案不执行。
- **L05 数据与隐私**｜线索、客户名单、声音、肖像、健康与家庭资料｜未经授权不得收集、出售、训练或转移。
- **L06 广告与推荐**｜品牌合作、联盟、导购和评价｜披露商业关系，不虚构交易、评价、效果或用户身份。
- **L07 投资与高风险资产**｜股票、基金、债券、股权、贵金属、外汇、加密资产和杠杆｜保留为风险与收益权候选；不把本金、账面盈利或借款当收入，不以不可承受损失资金投入。
- **L08 违法与欺骗方案**｜刷单、虚假交易、侵权、盗版、代考、诈骗、规避限购和侵犯他人权益｜不进入可执行机会池。

## 复核原则

新机会先放入 L1–L12 之一，记录它留下的是收入权、作品、能力、关系、流程、资产还是选择权；再列付款人、长期问题、交付和收益机制。低价、慢增长、没有受众、没有能力或最终可能不赚钱，都不是入池理由。只有具体权利不存在、必要条件无法合法取得，或方案本身欺骗、侵权、违规、违法时，才停止该具体方案。持续经营不等于必须扩张；达到足够、保留现金、减少承诺、迁移能力或退出，也属于长期结果。
