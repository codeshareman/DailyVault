# 中期收入机会清单：方式 × 人物画像

依据：[[中期赚钱方式：持续收入与有效积累]] · 参照：[[短期收入机会]]

> **这是机会池，不是最终筛选表。** 低客单价、低频复购、尚无受众、尚无成熟产品、需要先积累作品或能力的路径均保留。中期不是“已经稳定赚钱”，而是经过几个月至半年的持续投入后，开始检验：下一笔收入从哪里来、成果是否复用、获客是否可重复、客户关系是否留在自己手里、利润和承诺是否可承受。
>
> [推断] 每行是一个待验证的收入组合，不是市场结论、收益承诺或用户已有能力记录。现实世界不可能被一张清单绝对穷尽；新机会应按“已有／可建设筹码 × 人物画像 × 持续问题 × 交付方式 × 复购或积累机制”补入对应区域。

## 阅读与入池规则

- 不按客单价、当前能力、现有粉丝、已有订单、规模或可复制性筛选；这些都是验证变量。
- 中期候选至少关注一次重复发生：复购、续费、转介绍、新同类客户、旧作品持续使用、渠道持续带来需求，或同一流程可低成本复用。
- “月费、订阅、会员、终身更新”不是天然的中期模式。只有持续价值、交付能力、退款规则与支持边界明确时才作为候选。
- 低价产品可以通过复购、组合购买、分发或低支持成本形成中期假设；高价服务也可能只是一次性劳动，不能仅凭价格归入中期。
- 当前没有资质、工具、受众或供应链时保留候选并标记“条件待核”；未取得必要资格或授权前不执行。确认具体方案违法、侵权、欺骗或违反规则时不执行。
- 区分营业额、预收款、报销、押金、退款、本金回收、资产变现和净收入；持续承诺对应未来成本，必须单列。
- 保护个人信息、客户数据、版权、商业秘密和未成年人；核查所在地、平台、税费、保险、行业许可和消费者保护要求。
- 每条候选同时标注观察尺度：短期看首次交付与到账；中期看几个月内的复购、续费、转介绍、同类新客或复用；长期看跨年度的价值寿命、能力迁移、委托、转让与退出。一个候选可以同时进入不同机会池，但不重复维护事实。

## 中期持续性类型

| 类型 | 下一笔收入的来源 | 需要验证的积累 |
|---|---|---|
| C1 复购 | 同一客户再次购买 | 需求周期、体验和交付成本 |
| C2 续费 | 同一客户延长使用 | 持续价值、流失和支持成本 |
| C3 转介绍 | 老客户带来新客户 | 推荐原因、归因和服务质量 |
| C4 同类新客 | 新客户反复出现 | 内容、搜索、平台或销售渠道能否复现 |
| C5 复用资产 | 旧内容、代码、素材或流程继续产生价值 | 更新负担、权利和使用证据 |
| C6 关系／渠道 | 受众、合作方、供货或客户关系逐渐沉淀 | 控制权、替代渠道和转换成本 |
| C7 周转／利用率 | 库存、设备、空间或资金持续被使用 | 利用率、损耗、空置、风险与净额 |
| C8 能力／议价 | 作品、经验、资格或信誉提高后获得更好订单 | 真实选择理由、劳动成本和责任 |

## A｜重复性文件、行政与信息服务

- **A01 月度数据录入**｜小商户｜固定字段、固定日期持续录入｜按月／批；验证客户是否连续需要。
- **A02 月度订单核对**｜电商卖家｜订单、发货、退款差异表｜按月；验证错误率与人工时长。
- **A03 周期库存盘点**｜门店、仓库｜定期盘点与差异报告｜按次／月；验证盘点周期和责任。
- **A04 持续资料归档**｜小团队、个体经营者｜文件命名、目录、索引和归档规则｜按月／包。
- **A05 客户资料持续清洗**｜销售团队｜去重、字段规范、失效标记｜按批／月；数据授权待核。
- **A06 月度报表制作**｜小商户、项目负责人｜固定模板的经营或项目报表｜按月；验证模板复用和数据来源。
- **A07 会议纪要与行动项跟踪**｜项目团队｜会议记录、责任人和截止日期追踪｜按月／项目。
- **A08 招聘邀约与面试排期**｜小企业、招聘团队｜固定岗位的候选人联系和排期｜按岗位／月；不买卖个人信息。
- **A09 电商商品上架维护**｜网店卖家｜规格、图片、库存和页面更新｜按商品／月。
- **A10 门店信息维护**｜本地门店｜营业时间、地址、菜单等真实信息更新｜按店／月。
- **A11 费用与凭证整理**｜个体经营者｜授权原始材料分类和台账｜按月；不冒充会计鉴证。
- **A12 公开信息监测**｜采购、品牌和研究团队｜价格、政策、竞品或招投标信息摘要｜按周／月。
- **A13 行业资讯摘要**｜忙碌的从业者和管理者｜来源可追溯的定期摘要｜按期／订阅；先验证阅读与续订。
- **A14 招聘信息筛选**｜求职者、猎头或招聘方｜按条件筛选的职位／候选人清单｜按批／周期。
- **A15 招标、基金或活动机会整理**｜机构、小团队和创作者｜符合条件的公开机会清单｜按期；不保证中标。

## B｜持续技术支持与软件服务

- **B01 网站维护包**｜小商户、个人品牌｜固定频率更新、备份和小修复｜按月；范围与响应时间明确。
- **B02 轻量运维值守**｜小型网站、机器人或 API 团队｜日志检查、重启、告警转交｜按月；不承诺无限责任。
- **B03 定期性能巡检**｜网站运营者｜固定指标测量与趋势报告｜按月／季度。
- **B04 软件版本升级服务**｜不会自行升级的团队｜升级、兼容检查和回滚｜按次／维护包。
- **B05 数据备份与恢复演练**｜家庭、小团队｜备份检查和恢复测试｜按月；不能保证灾难后完整恢复。
- **B06 开发环境维护**｜学生、独立开发者、小团队｜依赖更新和环境修复｜按次／期。
- **B07 固定范围 bug 修复包**｜已有软件客户｜每期处理限定数量的问题｜按包；未处理问题另计。
- **B08 API 按量服务**｜需要单一自动化能力的用户｜可计量的真实接口结果｜按量／月；成本、限额和停服规则明确。
- **B09 微型 SaaS**｜有重复工作的小团队｜解决单一工作流的持续软件服务｜低价订阅／按量；验证留存和支持成本。
- **B10 插件持续更新**｜使用插件的开发者、设计师｜兼容版本、修复和有限支持｜按许可／订阅；不承诺所有宿主版本。
- **B11 自动化工作流维护**｜运营、行政和创作者｜固定流程的监测、修复和迭代｜按月／次。
- **B12 知识库持续维护**｜个人、小团队｜模板、索引、权限和结构更新｜按月；保护内部资料。
- **B13 有限技术支持订阅**｜使用既有工具的客户｜规定响应时段与问题数量的答疑｜按期；不把全天候支持藏在低价内。
- **B14 软件实施与培训包**｜购买工具的小团队｜配置、交接和新人培训｜按项目／阶段；后续维护另列。
- **B15 安全基线复查**｜自有网站和系统的团队｜授权范围内定期检查与报告｜按期；不替代完整审计或合规认证。
- **B16 数据看板维护**｜运营与管理团队｜更新数据源、指标和异常说明｜按月；指标定义与数据权限明确。

## C｜持续内容、媒体与受众变现

- **C01 垂直主题文章系列**｜有持续问题的读者、编辑或品牌｜连续原创文章｜稿费、赞助、付费阅读或授权；验证来源能否重复。
- **C02 教程系列**｜工具学习者和企业用户｜连续教程与案例｜按稿／数字包／合作。
- **C03 视频频道**｜需要持续信息、教育或娱乐的观众｜定期原创视频｜平台分成、赞助、品牌合作或产品销售；播放不等于收入。
- **C04 播客系列**｜特定兴趣和行业听众｜定期节目｜赞助、广告、会员或付费活动。
- **C05 Newsletter**｜需要筛选信息的专业人群｜定期邮件内容｜订阅、赞助、广告或服务线索。
- **C06 低价专题资料包**｜只需要解决一个窄问题的读者｜持续更新或按主题组合的原创资料｜按份／包；验证独立使用。
- **C07 免费内容＋付费深度稿**｜愿意先了解主题的读者｜免费样例与付费深度内容｜按篇／订阅；不假设粉丝转化。
- **C08 读者赞助／打赏**｜愿意支持作者的读者｜持续原创内容｜平台赞助；自愿金额不保证稳定。
- **C09 内容授权库**｜媒体、品牌和培训团队｜可检索、可重复许可的原创内容｜按期／按许可；版权链清楚。
- **C10 品牌内容合作**｜需要特定受众触达的品牌｜长期或多期内容交付｜按项目／合作；广告披露与使用权明确。
- **C11 垂直社群**｜需要交流、资源或同行支持的人｜持续组织和管理｜会员费、赞助、活动费；管理成本与承诺待核。
- **C12 付费问答／办公时间**｜持续遇到相近问题的用户｜固定时间答疑｜按次／会员；不是无限私教。
- **C13 线上小型活动系列**｜学习者、创作者或行业人群｜定期分享、讨论或工作坊｜按场／期／赞助。
- **C14 受众导向的联盟导购**｜有明确购买问题的受众与官方联盟商｜真实比较和推荐｜按合格成交；归因、披露和退款扣回待核。
- **C15 开源项目赞助**｜受益用户与企业｜持续维护和公开交付｜赞助；附加支持义务单独收费。
- **C16 开源项目商业支持**｜使用开源工具的团队｜部署、培训、排障和定制｜按项目／支持包；许可证与服务分开。
- **C17 作品集持续更新服务**｜创作者、开发者和求职者｜定期整理新作品与案例｜按期／次。
- **C18 本地生活内容入口**｜附近消费者和商户｜持续制作本地攻略、评价和信息｜广告、合作或线索；真实披露，不刷评价。

## D｜数字产品、模板与知识资产

- **D01 低价模板店**｜学生、职场人和小商户｜多个窄用途模板｜按份／组合；低客单价保留，验证下载、使用和支持成本。
- **D02 工作簿与计算器系列**｜预算、报价、库存或计划用户｜可独立使用的原创工作簿｜按份／包。
- **D03 项目管理模板库**｜小团队、自由职业者｜任务、会议、交付和复盘模板｜按包／授权。
- **D04 求职材料模板库**｜求职者｜简历、作品集和面试准备材料｜按包；不伪造经历。
- **D05 学习资料与练习包**｜学生、自学者｜原创讲义、题型说明与练习｜按包；不代考代写。
- **D06 商户运营表格包**｜小商户｜订单、库存、排班、成本和客户记录模板｜按包／许可。
- **D07 内容创作素材包**｜博主、品牌和剪辑者｜原创图形、音效、脚本或提示词素材｜按包／许可。
- **D08 开发者脚手架与组件**｜开发者和小团队｜代码、配置与文档｜按许可／支持包。
- **D09 小型插件与自动化工具**｜有重复工作的用户｜处理单一问题的工具｜低价许可／订阅；验证更新与兼容成本。
- **D10 数据目录与研究汇编**｜研究者、采购和创作者｜持续更新的合法目录｜按期／许可；来源和更新频率明确。
- **D11 课程材料库**｜培训者和学习者｜可复用的课件、练习和案例｜按包／许可。
- **D12 录播微课程**｜需要掌握窄技能的学习者｜固定内容与练习｜按份；答疑另计。
- **D13 付费专题数据库**｜需要持续查询的专业用户｜合法整理、搜索和更新的信息｜按期／按量；维护与版权待核。
- **D14 原创电子书系列**｜围绕一个持续主题的读者｜多卷内容或更新版｜按本／包／授权。
- **D15 设计系统／品牌资产包**｜小团队和创作者｜可复用的组件、规范和素材｜按许可／项目。
- **D16 可持续更新的模板订阅**｜每月有相似工作需求的用户｜新增模板与版本更新｜订阅；验证续费而非只看首购。
- **D17 数字下载市场店铺**｜有明确小问题的买方｜多个低价数字成品｜按份；平台费、退款和盗用待核。
- **D18 可转让的域名、网站或数字项目**｜项目收购者｜有权转移的数字资产｜一次性转让；与持续经营分开。

## E｜培训、辅导、陪跑与专业关系

- **E01 固定主题小班课**｜同类学习需求的人｜重复使用的课程和练习｜按期／人；验证满班与准备时间。
- **E02 企业工具培训**｜小团队和企业｜针对岗位的培训与材料｜按场／包。
- **E03 编程学习陪跑**｜学生和转行者｜固定周期目标、答疑与复盘｜按期；不代做作业。
- **E04 语言学习陪练计划**｜持续学习的成年人｜固定频率练习与反馈｜按期／次。
- **E05 作品集迭代辅导**｜设计师、开发者和求职者｜多轮作品改进｜按期／包。
- **E06 面试准备辅导**｜求职者｜岗位分析、模拟和反馈｜按包；不保证录用。
- **E07 个人知识管理陪跑**｜希望建立记录习惯的人｜固定周期配置、复盘和指导｜按期；不承诺心理或人生结果。
- **E08 小商户运营陪跑**｜刚开始经营的商户｜固定周期指标、流程和复盘｜按月；不保证营业额。
- **E09 技术顾问小时包**｜没有全职技术人员的小团队｜限定问题的持续咨询｜按小时包／期。
- **E10 合规财税顾问服务**｜个体户和企业｜在资格范围内的持续服务｜按期；无资质不执行。
- **E11 合规法律顾问服务**｜有持续法律事务的组织｜在执业范围内提供服务｜按期；无资格不执行。
- **E12 合规医疗／心理服务**｜有对应需求的服务对象｜符合执业与安全要求的服务｜按次／期；不以普通陪伴替代专业服务。
- **E13 教练、健身或运动计划**｜有持续训练目标的人｜计划、反馈和陪练｜按期；健康风险和资质待核。
- **E14 宠物训练与持续照护**｜宠物主人｜固定训练或照护周期｜按期；动物安全与责任待核。
- **E15 家庭收纳／清洁维护包**｜家庭和房屋使用者｜固定周期服务｜按月／次；人员安全和财产责任明确。
- **E16 老人数字生活持续协助**｜老人及家属｜定期设备、软件和线上事务协助｜按月／次；不接触支付凭据。
- **E17 企业文档与知识库维护**｜团队和软件项目｜持续更新文档、流程与知识库｜按月／项目。
- **E18 翻译／本地化维护包**｜持续发布内容的出海团队｜新版本、产品和帮助文档翻译｜按月／字数；术语库沉淀。

## F｜本地生活、线下重复服务与照护

- **F01 定期家庭保洁**｜家庭、租户、短租房东｜固定周期清洁｜按次／月。
- **F02 定期收纳维护**｜家庭、工作室和小门店｜换季、搬迁或周期整理｜按次／期。
- **F03 宠物寄养／上门照看**｜经常出差的宠物主人｜固定照护关系｜按天／期；安全和责任待核。
- **F04 植物养护**｜办公室、民宿和家庭｜定期浇水、修剪和检查｜按月／次。
- **F05 老人非医疗陪同**｜老人及异地家属｜固定就医、办事或购物陪同｜按次／包；资格边界待核。
- **F06 儿童课后照护**｜双职工家庭｜固定时段照护｜按时／月；当地许可、安全和背景要求待核。
- **F07 家庭临时维修维护**｜房屋使用者、房东｜周期小修、安装和检查｜按次／维护包；高风险项目需资质。
- **F08 服装、鞋包清洁维护**｜个人、门店和剧组｜固定周期或批量处理｜按件／包。
- **F09 车辆清洁与基础维护**｜车主、车队｜定期清洁、检查或非专业保养｜按次／月；维修资质另核。
- **F10 家庭网络和设备维护**｜家庭、小办公室｜定期检查、升级和排障｜按次／维护包。
- **F11 社区代购与配送**｜行动不便者、老人和附近家庭｜固定区域的代购取送｜按次／期；商品款、服务费和合规要求分列。
- **F12 本地摄影与旅拍**｜家庭、游客和小商户｜周期活动、门店和家庭拍摄｜按场／包；肖像和场地授权明确。
- **F13 小型活动执行团队**｜社区、婚礼、展会和品牌｜持续承接布置、撤场与执行｜按场／项目。
- **F14 活动设备与道具租赁**｜活动方、摄影团队和家庭｜设备、服装、道具重复出租｜按天／场；利用率、损坏和清洁成本待核。
- **F15 车位、储物空间或场地出租**｜附近临时使用者｜重复时段使用权｜按期；产权、物业与安全规则待核。
- **F16 合规短租房源经营**｜出差、旅游和过渡居住者｜持续住宿使用权｜按晚／期；当地规定和房东授权待核。
- **F17 本地课程或兴趣社群**｜同城学习、运动和兴趣人群｜定期场地、课程或活动｜按期／场；场地、保险和安全待核。
- **F18 低价社区服务包**｜附近居民｜组合清洁、取送、整理或设备协助｜低价按次／月；验证路线和时间密度。

- **G09 办公与活动用品供应**｜小团队、社团和活动方｜固定品类采购与配送｜按批；供货、资金和退货待核。

- **G12 节庆／季节性商品**｜节日和活动消费者｜按季节采购、预售和交付｜按件；预售款与收入分开。

## H｜销售、代理、引荐与渠道

- **H01 官方联盟推荐**｜提供推荐计划的服务商｜真实内容与合格转化｜按佣金；小额也保留。
- **H02 B2B 服务商线索**｜缺少客户的开发、设计、维修和咨询服务商｜经同意的合格线索｜按线索／成交；隐私合规待核。
- **H03 本地服务撮合**｜需要保洁、维修、照护或活动服务的客户｜匹配合规供给方｜按服务费／佣金。
- **H04 供应商采购撮合**｜需要稳定供货的商户｜真实供应商比较与连接｜按项目／成交；利益披露。
- **H05 授权销售代理**｜商品和服务供给方｜持续销售与客户跟进｜按佣金／底薪；代理权明确。
- **H06 授权经销商**｜需要软件、工具或商品的客户｜合规产品销售与售后转接｜按件／期；不转售个人账号。
- **H07 招聘推荐**｜有岗位的雇主｜符合规则的候选人推荐｜按成功入职；许可、同意和归因待核。
- **H08 房源、车位或场地经纪**｜供需双方｜授权范围内匹配｜按佣金；行业资格待核。
- **H09 创作者商务代理**｜品牌与创作者｜授权合作谈判和交付协调｜按服务费／佣金。
- **H10 企业采购代理**｜需要持续采购的小团队｜比价、下单和供应商管理｜按服务费；不隐瞒返佣。
- **H11 社群团购组织**｜社区消费者与供给方｜真实需求汇总和合规采购｜按组织费／佣金；不虚构销量。
- **H12 内容分发合作**｜有作品的作者与媒体、品牌｜按授权分发和结算｜按稿费／许可／分成。
- **H13 本地商户客源合作**｜门店与附近消费者｜内容、活动和真实线索｜按合作／成交；广告披露。
- **H14 多边平台小店经营**｜平台买方｜持续上架、销售和售后｜按成交；平台规则和退款待核。
- **H15 渠道白标／联营服务**｜需要自有品牌服务的小团队｜授权的后台能力加本地交付｜按期／项目；责任和品牌权利清楚。
- **H16 续费与客户成功服务**｜软件或服务供应商｜客户使用跟进、培训和续费协助｜按月／续费佣金；不虚报使用效果。

- **J14 会员支持与赞助**｜读者、用户或企业｜持续公开维护或内容｜按月／次；承诺边界明确。

## K｜资产利用、许可与金融现金流

- **K01 设备循环出租**｜摄影、活动、办公和兴趣用户｜同一设备多次出租｜按天／场；利用率和损坏率待核。
- **K02 服装与道具租赁**｜拍摄、演出和活动团队｜重复使用的服装道具｜按场／天。
- **K03 场地、车位与储物出租**｜附近临时使用者｜持续使用权｜按期；产权、物业和安全待核。
- **K04 合规房屋出租**｜稳定或短期居住者｜居住使用权｜按期；租约和当地规则待核。
- **K05 原创作品非排他授权**｜媒体、品牌、培训方｜同一作品向不同主体授权｜按许可；排他条款与权利链核对。
- **K06 软件、组件或模板许可**｜开发者、小团队和企业｜按席位、期限或项目使用｜按许可／续费；支持成本单列。
- **K07 内容库订阅许可**｜持续使用素材的团队｜定期访问原创内容库｜按期；更新义务与版权待核。
- **K08 域名、网站或数字项目出租／转让**｜需要现成入口或项目的买方｜有权处分的数字资产使用或所有权｜按期／一次性；与运营收入分开。
- **K09 已有存款、债券或合规资产的利息／分配**｜银行、发行方或项目方｜按合同或规则产生的收益｜按期；本金与收益分开。
- **K10 已有金融或实物资产变现**｜市场实际买方｜合法持有资产的所有权转移｜成交后；本金、费用、税费和盈亏分开。
- **K11 高波动资产价格机会**｜市场实际买方｜资产头寸的价格变动｜不确定；保留为高风险财务候选，不当作经营收入或现金流方案。
- **K12 资金配置与债务优化服务**｜有财务管理需求的客户｜仅在必要资格和边界满足后提供信息整理或专业服务｜按次／期；不承诺收益。
- **K13 资产出租＋维护服务**｜资产使用者｜使用权与定期维护组合｜按期；租赁、劳动和责任分别核算。
- **K14 许可＋定制服务**｜需要授权内容并要求修改的企业｜作品许可与定制交付｜按许可＋项目；不能把工时隐藏在授权费内。

- **L15 数据产品与研究服务**｜持续需要信息的企业、研究者和创作者｜合法数据、更新流程和解释能力｜订阅／报告／许可。
- **L16 社群与活动品牌**｜需要交流、学习、资源或合作的人｜持续组织、内容和关系｜会员、活动费、赞助或服务。
- **L17 创作者商务渠道**｜品牌与创作者｜作品、受众和合作流程｜服务费／佣金；不把粉丝数等同于付费意愿。
- **L18 教练／顾问订阅**｜持续需要反馈的客户｜周期性目标、反馈与复盘｜按期；承诺、容量和退出条件明确。
- **L19 订阅式本地配送或维护**｜固定消耗或维护需求的家庭、门店｜周期履约路线｜按期；利用率和取消规则待核。
- **L20 合规软件／工具经销渠道**｜企业、创作者和开发者｜授权产品、续费和售后转接｜按销售／续费佣金；不共享账户。

## M｜组合经营候选：多个收入机制如何连接

- **M01 免费内容 → 低价模板 → 有限配置服务**｜先解决理解、成品和个别帮助三种不同问题｜分别验证阅读、购买和服务容量。
- **M02 免费工具 → 付费插件／托管 → 企业支持**｜个人用户与团队用户｜验证免费使用是否形成付费需求，不把流量当收入。
- **M03 低价试单 → 服务包 → 维护续费**｜风险敏感的小商户和团队｜小结果、固定交付和持续责任分开报价。
- **M04 本地服务 → 排班团队 → 服务包**｜附近家庭和商户｜验证复购、人员质量和管理成本。
- **M05 模板商品 → 定制服务 → 企业授权**｜从个人低价买方到团队客户｜权利、支持与定制工时分开。
- **M06 内容受众 → 联盟推荐 → 自有数字产品**｜有明确购买问题的垂直人群｜披露推荐关系，不能预设转化。
- **M07 二手交易 → 检测翻新 → 租赁服务**｜低预算买家与临时使用者｜所有权、维修责任、租赁利用率分别验证。
- **M08 手作商品 → 企业礼品 → 周期补货**｜个人送礼者、活动方和企业｜小单、批量单与复购不是同一需求。
- **M09 研究报告 → 数据订阅 → 咨询服务**｜需要信息、持续更新和判断的客户｜报告交付、数据库权利与专业意见边界分开。
- **M10 开源项目 → 文档培训 → 商业支持**｜个人使用者和企业｜许可证、赞助与付费支持各自验证。
- **M11 内容制作 → 内容库授权 → 品牌长期合作**｜品牌与媒体｜成片、许可和合作排期分开核算。
- **M12 设备出租 → 配送安装 → 维护包**｜活动方、商户和家庭｜资产使用、劳动和维护责任分别记录。
- **M13 课程 → 小班辅导 → 企业培训**｜自学者、小组和企业｜低价内容、实时教学和企业交付分别验证。
- **M14 线索内容 → 撮合服务 → 代理／经销**｜买方、供给方和品牌｜线索、成交和代理权分别核对。
- **M15 老客户 → 追加功能 → 续费维护**｜已有客户｜新需求、售后义务和持续服务不重复收费。
- **M16 社群 → 活动 → 赞助／合作**｜成员、活动方和品牌｜成员价值、活动收入和赞助权益分开。
- **M17 产品销售 → 安装培训 → 周期耗材**｜不会使用或持续消耗产品的买方｜商品、劳动和复购分别核算。
- **M18 个人品牌 → 分包协作 → 工作室**｜多个同类客户｜先验证客户来源与交付标准，再增加固定承诺。

## N｜不得混为收入的中期现金来源

- **N01 已有合同尾款、租金、版税和佣金**｜已有权利或合同｜按实际结算核对，不是新机会。
- **N02 退款、押金、预付款返还**｜原交易相对方｜取回自己的钱，不是收入。
- **N03 报销**｜雇主或委托方｜真实成本补偿，不能与报酬合并。
- **N04 补贴、退税、赔付和保险理赔**｜主管机构、保险机构或责任方｜按规则单列，不预估到账。
- **N05 债务、借款和代垫款回收**｜原债务人｜本金回收不等于新增收入。
- **N06 赠与、家庭支持和赞助**｜赠与人、家人或支持者｜转移或赞助，若附交付义务需另记。
- **N07 资产本金变现**｜市场买方｜本金、费用和盈亏分开。
- **N08 预售与年费预收**｜客户｜现金已收但未来仍有履约责任，不能全额当期收入。

## O｜具体方案边界

- **O01 资质待核不等于机会排除**｜会计、法律、医疗、心理、儿童照护、驾驶、高风险维修等方向保留为候选｜取得许可、保险和安全条件前不执行。
- **O02 未授权转售不执行**｜账户、订阅、会员权益、票券和数字内容只有在具体规则允许时才进入合法候选｜可以研究官方分销、可转让券种或独立服务。
- **O03 票务按具体规则判断**｜普通授权代订、明确可转让余票、规避实名／限购／转售限制是三个不同方案｜后者不执行。
- **O04 真实广告与联盟推荐**｜需要披露商业关系、不能虚构评价、交易或效果｜低佣金也保留。
- **O05 数据与内容授权**｜客户数据、个人信息、声音、肖像、代码、图片和字体都需核权利与用途｜不因买方愿意付费而获得授权。
- **O06 高风险金融机会**｜投资、投机、杠杆、外汇和加密资产可作为背景研究｜不作为稳定中期收入，不把账面收益当到账。
- **O07 负债与融资**｜借款、信用额度和周转垫资可提供现金但不是收入｜单独记录本金、利息和偿还责任。

观察尺度：短期首次交易／中期重复性／长期价值留存（可多选）

## 复核原则

新想到一个机会时，先标记：**一次性交易、重复性来源、积累资产、持续承诺、主要控制权**。如果只是把同一服务改名、换平台或改变计费单位，不重复制造候选；如果付款人、问题、交付或持续机制改变，则建立独立组合。候选阶段不因低客单价、低频、没有能力、没有受众或需要建设而删除；只在具体验证中记录条件、成本、风险与证伪信号。
