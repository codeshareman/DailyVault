# 中国政府采购网

[官方网站](https://www.ccgp.gov.cn/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 采购意向、采购公告、合同公告及相关信息 |
| 浏览方式 | 按关键词和公告类型检索 |
| 来源 | `url` |

## 它是什么

中国政府采购信息发布平台。官网说明其为财政部唯一指定的政府采购信息网络发布媒体。

## 为什么值得收藏

- 可观察组织对报表、档案、数据治理和流程自动化等能力的采购语言。

## 适合什么时候使用

- 研究 B2B 需求规格、预算级别和合规限制时。

## 使用限制

- 项目总预算不能直接换算为单个工具价格；参与采购前须另行核验资质、规则与交付能力。
