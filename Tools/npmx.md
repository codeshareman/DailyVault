# 浏览和比较 npm 包

[npmx](https://npmx.dev/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | npm Registry 包搜索、浏览与元数据 |
| 使用方式 | 输入包名或关键词后检查候选包 |
| 定价 | 公开访问 |

## 它是什么

npmx 是 npm Registry 的第三方现代化浏览器，用于发现包并快速查看其元数据与相关信息。

## 为什么值得收藏

- 比直接在搜索引擎中找包更聚焦，可用于候选包初筛。
- 适合作为进入 npm Registry 和项目仓库前的浏览入口。

## 适合什么时候使用

- 需要寻找 JavaScript/TypeScript 依赖或比较同类包时。
- 需要快速定位包名、版本与上游项目时。

## 使用限制

- 第三方界面不能替代 npm Registry、源码仓库和官方文档。
- 采用依赖前仍需核对维护状态、许可证、安全记录、体积和锁文件变化。
