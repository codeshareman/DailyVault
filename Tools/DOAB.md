# DOAB｜开放获取学术图书目录

[官方网站](https://www.doabooks.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放获取图书发现索引 |
| 内容 | 同行评审的学术开放获取图书及出版者信息 |
| 获取方式 | 检索后跟随条目链接访问出版者或存储库版本 |

## 它是什么

DOAB（Directory of Open Access Books）是社区驱动的发现服务，索引同行评审的学术开放获取图书，并帮助用户发现可信的开放获取出版者。

## 适合什么时候使用

- 按学科、出版者、语言或关键词查找开放获取学术专著时。
- 核对某本学术书是否被开放获取图书目录收录时。

## 下载与授权限制

- DOAB 是索引而非统一文件主机；下载发生在具体条目指向的出版者或存储库，是否有 PDF、EPUB 与何种许可均逐条不同。
- “开放获取”不自动等于无限制再利用，须读取目标书的许可与署名要求。

## 我的判断

- 查找可信学术 OA 图书时应优先使用；把它作为发现与许可核验入口，而不是直接下载承诺。
