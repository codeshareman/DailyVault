# Excalidraw

[官方网站](https://excalidraw.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 支持协作的虚拟白板工具，可方便绘制具有手绘风格的图表。 |
| 浏览方式 | 直接访问公开页面 |

## 它是什么

面向图解和协作的在线白板，强调易于绘制的手绘视觉风格。

## 为什么值得收藏

- 适合把流程、架构和讨论内容快速沉淀为直观图解。

## 适合什么时候使用

- 需要以手绘风格制作流程图、架构图或讨论草图时。

## 我的判断

- 适合作为通用协作图解工具；具体功能与可用性以官网为准。
