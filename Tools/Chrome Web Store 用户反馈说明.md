# Chrome Web Store 用户反馈说明

[官方网站](https://developer.chrome.com/docs/webstore/support-users)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 扩展用户评价跟进与支持说明 |
| 浏览方式 | 阅读官方文档并从商城进入用户反馈 |
| 来源 | `url` |

## 它是什么

Chrome Web Store 面向扩展开发者的用户支持文档。

## 为什么值得收藏

- 明确从官方文档进入扩展用户反馈的路径。

## 适合什么时候使用

- 研究浏览器扩展评价、开发者回复和支持入口时。

## 使用限制

- 文档说明支持流程，不等于当前具体扩展的用户问题或付款证据。
