# OpenStax｜开放教育教材

[官方网站](https://openstax.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放教材主机与教育资源平台 |
| 内容 | 同行评审教材及配套课程资源 |
| 获取方式 | 在教材页在线阅读或使用页面提供的可用格式 |

## 它是什么

OpenStax 提供面向中学后教育的免费、同行评审开放教育教材和课程资源。

## 适合什么时候使用

- 查找基础学科的可教学、可引用开放教材时。
- 为课程选择具有公开版本的主教材或补充读物时。

## 下载与授权限制

- 教材的在线阅读和文件形式以具体页面为准，附加产品或第三方资源可能适用不同条件。
- 请按每本教材列出的许可和署名规则使用，不要假定所有配套内容均可自由再分发。

## 我的判断

- 是高等教育基础教材的优先选择；适合课程采用，但应逐书核对版本、许可和本地适用性。
