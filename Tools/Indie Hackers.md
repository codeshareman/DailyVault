# Indie Hackers

[官方网站](https://www.indiehackers.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 独立创业、产品、获客、运营和用户经验 |
| 浏览方式 | 浏览公开帖子、主题与讨论 |
| 来源 | `url` |

## 它是什么

面向独立创业者和小型在线业务的讨论社区。

## 为什么值得收藏

- 可观察创业者自述的工作流、用户访谈与运营难点。

## 适合什么时候使用

- 研究小型在线业务的流程与产品供给时。

## 使用限制

- 收益自述、推广帖和产品发布不是独立需求证据；需区分创作者观点与买家反馈。
