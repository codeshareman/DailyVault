# 中国高等教育学生信息网（学信网）

[官方网站](https://www.chsi.com.cn/)

## 它是什么

学历、学籍、学位核验和招生信息服务平台，常用于考试报名资格审核。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
