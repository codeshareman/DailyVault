# 中国教育考试网

[官方网站](https://www.neea.edu.cn/)

## 它是什么

教育部教育考试院官方考试信息与报名导航平台，覆盖教师资格、四六级、PETS、NCRE等项目。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
