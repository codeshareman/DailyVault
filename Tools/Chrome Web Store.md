# Chrome Web Store

[官方网站](https://chromewebstore.google.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | Chrome 扩展、主题、评分与开发者信息 |
| 浏览方式 | 按任务搜索并比较评价、更新与回复 |
| 来源 | `url` |

## 它是什么

Google Chrome 的扩展与主题分发平台。

## 为什么值得收藏

- 可观察批量处理、标签页、资料收集和导出等浏览器任务。

## 适合什么时候使用

- 研究浏览器扩展的用户场景、评价和支持问题时。

## 使用限制

- 评价是个体反馈；本次未逐条抽样，不据评分推断市场规模。
