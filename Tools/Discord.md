# Discord

[官方网站](https://discord.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web / App |
| 内容 | 主题服务器、频道、消息和社区讨论 |
| 浏览方式 | 从目标产品官网的 Community 链接进入服务器 |
| 来源 | `url` |

## 它是什么

面向主题社群的实时通信平台。

## 为什么值得收藏

- 官方服务器中的 help、feedback 等频道可能包含持续的产品使用问题。

## 适合什么时候使用

- 获得授权后研究插件、产品和创作者工作流的长期问题时。

## 使用限制

- 服务器可能需要登录或邀请；平台首页本身不提供目标用户样本，不得未经授权采集私域内容。
