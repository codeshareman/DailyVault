# PriceAI｜AI 订阅与中转 API 渠道比价

[官方网站](https://priceai.cc/channels)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web；另有 Telegram 与 GitHub 入口 |
| 内容 | AI 订阅、卡网渠道、中转 API 的价格、来源、库存与更新时间比较 |
| 覆盖对象 | ChatGPT、Claude、Gemini、Grok、邮箱、接码等数字服务 |
| 浏览方式 | 按产品、交付方式和渠道查看公开报价；支持批发合作入口 |
| 开源入口 | [PriceAI GitHub](https://github.com/physics-dimension/PriceAI) |

## 它是什么

PriceAI 是一个 AI 低价订阅与中转 API 比价雷达。`/channels` 页面按产品展示渠道报价，并区分代充、成品账号、共享、卡密、激活服务和其他待确认交付方式；部分条目还显示来源、库存和更新时间。

## 为什么值得收藏

- 将分散的 AI 订阅和中转 API 渠道放到同一入口，适合做初步价格与供给观察。
- 按交付方式区分报价，避免把代充、账号、共享、卡密和 API 访问混成同一种商品。
- 页面提供渠道、库存和更新时间等字段，可作为后续核验供应商、交付条件和实际成本的线索。
- 提供公开 GitHub 项目和社区入口，便于追踪项目维护与使用说明。

## 适合什么时候使用

- 比较 AI 订阅、卡网服务和中转 API 的公开渠道报价时。
- 调研 AI 数字服务的供给方式、交付差异和价格区间时。
- 为某个具体产品建立候选渠道清单，再回到原渠道和官方服务条款核验时。

## 使用限制

- 价格、库存、渠道状态、更新时间和交付期限会变化；页面报价不能替代下单前确认。
- 代充、成品账号、共享账号、卡密、激活服务和中转 API 的账户安全、隐私、稳定性、退款和合规风险不同。
- 中转 API 的实际可用模型、速率限制、上下文能力、数据处理方式和服务持续性必须通过服务商文档与实际测试确认。
- “低价”“有货”或渠道展示不等于服务商背书、交易安全、长期可用或授权完整；不能仅凭列表推断利润。
- 跨区、共享、代充、账号转让和第三方 API 使用可能受到原服务商条款限制；购买或接入前应独立核对规则。
- 本卡只记录公开入口，不保存账号、密码、API Key、验证码、支付信息或私密交易链接。
