# ERIC｜教育研究文献服务

[官方网站](https://eric.ed.gov/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 教育研究发现索引与部分全文入口 |
| 内容 | 期刊与非期刊教育研究文献的书目、摘要和链接 |
| 获取方式 | 从记录页查看 ERIC 全文或前往外部来源 |

## 它是什么

ERIC 是美国教育部支持的教育研究在线图书馆，收录期刊和非期刊教育文献的发现记录。

## 使用与授权

- 适合做教育学系统检索、报告发现、政策研究和教育主题文献综述。
- 记录可能仅含摘要或书目信息；仅在条目明确提供时才有全文，下载和再利用仍受原始文献版权与许可限制。

## 我的判断

- 教育研究的核心发现入口；在综述中应将 ERIC 索引记录与实际可获取全文明确区分。
