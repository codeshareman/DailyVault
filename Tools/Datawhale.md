[Datawhale](https://www.datawhale.cn/home)

## 它是什么

Datawhale 是面向中文 AI 学习者的开源学习社区与项目生态，不是单一 SaaS 或单门课程。它通过官网和 GitHub 组织提供教程、代码、组队学习与协作项目，并用项目流程区分筹划、内测、公测和成熟阶段。

## 为什么值得收藏

- 将中文 AI 教程、实践代码和协作机会集中到持续维护的组织入口。
- 适合从主题学习进入可运行项目，而不是只收藏零散文章或课程链接。
- 项目阶段、README、提交记录与许可证提供了继续筛选的依据。
- 社区和 GitHub 组织仍有近期活动，不是一次性资源聚合页。

## 适合什么时候使用

- 想系统学习某个 AI 主题并配合代码实践时。
- 需要寻找中文教程、学习路线或组队活动时。
- 希望参与开源教程、代码项目或社区协作时。
- 需要从社区入口继续定位具体项目与维护者时。

## 使用限制

- 社区覆盖面广，内容质量、维护频率、许可证和成熟度需要逐项目检查。
- Alpha/Beta 项目不应直接当成稳定生产方案；使用前应查看 README、最近提交和阶段标识。
- 部分活动依赖中文社区、微信群或特定本地环境，不一定适合只需要官方英文文档的场景。
- 收藏的是筛选入口，不代表自动认可组织中的每个项目。
