# Omarchy

[官方网站](https://omarchy.org/) · [手册](https://omarchy.org/manual/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Linux（基于 Arch；桌面为 Hyprland + Quickshell） |
| 内容 | 开箱即用的开发者向发行版：默认软件集、主题化桌面 shell、Agent 协助排查与定制 |
| 浏览方式 | 官网介绍与公开手册；需下载 ISO 安装 |

## 它是什么

Omarchy（oma = omakase）是一套意见鲜明的 Arch 系 Linux：由维护者选好基线配置与常用软件，安装后尽量立刻能干活，同时允许你改掉不满意的部分。官网把它定位为面向 Agent 时代的可塑系统——首次启动可配置默认 Agent，崩溃通知可交给 Agent 诊断，并附带帮助 Agent 制作应用、插件与主题的 skills。

## 为什么值得收藏

- 想评估「开发者默认栈 + tiling WM + Agent 运维」一体发行版时，官网与手册是直接入口。
- 相对从零配 Arch / Hyprland，它把安装、默认应用与桌面 shell 收成一条可跟进的产品线（当前公开信息指向 4.x Quattro 等大版本）。
- 与多 Agent 开发工具（如 Orca）形成对照：一边是开发环境，一边是整机 OS 层面对 Agent 的承接。

## 适合什么时候使用

- 考虑换用或试用面向开发者的 Linux 桌面，并关心 Agent 能否参与修系统、改主题时。
- 需要对照 ISO 安装、双系统、全盘加密等公开安装说明时。

## 我的判断

- 适合作为「agentic / omakase Linux」候选入口；具体硬件支持、安装风险（全盘安装会擦盘）、默认软件清单与 Agent 能力以 [官网](https://omarchy.org/) 和 [手册](https://omarchy.org/manual/) 为准。
- 风格偏 tiling + 终端重；不是要尽量像 Windows / macOS 的发行版。
