# Internet Archive｜数字资料库与受控借阅平台

[官方网站](https://archive.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 直接下载主机与受控借阅提供方 |
| 内容 | 数字化文本、音视频、软件与网页存档等 |
| 获取方式 | 按条目页的阅读、下载或借阅选项使用 |

## 它是什么

Internet Archive 将自己定位为数字图书馆，收录可免费使用和可借阅的文本、影音资料、软件及网页存档。

## 适合什么时候使用

- 检索馆藏扫描件、历史网页或多媒体资料时。
- 需要确认某一条目是可下载、仅在线阅读还是可借阅时。

## 下载与授权限制

- 不能把馆藏总量视为可自由下载清单：有些条目直接提供文件，有些采用借阅、登录或其他访问限制。
- 权利状态、使用许可和地域可用性以每个条目及其权利声明为准，不得绕过平台访问控制。

## 我的判断

- 覆盖面极广，适合作为资料发现与馆藏核验入口；下载前必须先看单条目的访问方式和权利信息。
