# ISBNdb｜ISBN 与图书元数据服务

[官方网站](https://isbndb.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 图书元数据索引 |
| 内容 | ISBN、题名、作者、出版与相关书目信息 |
| 获取方式 | 在网站或其提供的产品接口中查询元数据 |

## 它是什么

ISBNdb 是围绕 ISBN 和图书书目数据的检索服务，提供图书、作者和出版信息等元数据。

## 使用与授权

- 适合用 ISBN 核对版次、出版信息、作者记录或做书目数据补全。
- 它不托管图书全文；元数据查询、API 使用和数据再利用须依照服务的产品及条款，不能从书目记录推断下载权。

## 我的判断

- 适合做 ISBN 与版本核验；对内容获取没有替代图书馆、出版社或 OA 主机的作用。
