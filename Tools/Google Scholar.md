# Google Scholar｜学术文献发现索引

[官方网站](https://scholar.google.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 学术发现与引文索引 |
| 内容 | 论文、图书、引文、作者及外部访问链接 |
| 获取方式 | 检索后前往出版者、存储库或图书馆链接 |

## 它是什么

Google Scholar 是面向学术文献及其引文关系的检索服务，聚合并指向多种外部来源。

## 使用与授权

- 适合快速做题名、作者、被引和相关文献发现。
- 它通常不托管全文；搜索结果、PDF 标记或图书馆链接不等于合法公开下载，须在目标来源核对权限。

## 我的判断

- 适合作为文献检索起点；用它发现线索，再通过出版者、机构库或图书馆确认版本和访问权。
