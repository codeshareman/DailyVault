# 用路线图检查前端知识缺口

[Frontend Developer Roadmap](https://roadmap.sh/frontend)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 技能路线、主题说明、项目建议与学习资源 |
| 使用方式 | 以路线图定位知识缺口，再回到一手文档学习 |
| 定价 | 公开内容为主 |

## 它是什么

roadmap.sh 用可视化路线图组织开发角色所需的主题。前端路线覆盖 HTML、CSS、JavaScript、可访问性、版本控制、测试、性能、框架和 TypeScript 等领域。

## 为什么值得收藏

- 适合检查学习覆盖面，而不是继续积累零散教程链接。
- 可把模糊的“学前端”转成可选择、可排序的主题。

## 适合什么时候使用

- 制定阶段性学习计划或复盘知识缺口时。
- 转换技术方向、准备面试或规划练习项目时。

## 使用限制

- 路线图不是权威课程、项目规范或必须全部完成的清单。
- 内容会变化；具体技术结论应回到标准、框架和工具的一手文档。
