# World Bank Open Knowledge Repository｜世界银行开放知识库

[官方网站](https://openknowledge.worldbank.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 机构研究成果存储库与潜在直接下载主机 |
| 内容 | 世界银行报告、书籍、工作论文和知识产品 |
| 获取方式 | 从条目页使用在线阅读、文件和引用信息 |

## 它是什么

World Bank Open Knowledge Repository 是世界银行的开放知识存储库，集中呈现其研究与知识产品。

## 使用与授权

- 适合查找发展、经济、教育、治理等议题的世界银行正式研究成果。
- 许多条目提供文件，但格式、版本、许可和第三方材料限制以具体条目为准；下载不当然包含再发行权。

## 我的判断

- 是发展研究的权威一手来源；引用前应保存 DOI、正式版本和条目版权说明。
