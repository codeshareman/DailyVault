# Crossref｜DOI 与学术出版元数据基础设施

[官方网站](https://www.crossref.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | DOI 注册与学术元数据服务 |
| 内容 | DOI、出版物、引文、作者和许可等相关元数据 |
| 获取方式 | 查询元数据、DOI 解析结果或官方 API |

## 它是什么

Crossref 是学术出版领域的 DOI 注册机构和元数据基础设施，为出版物建立持久标识和关联数据。

## 使用与授权

- 适合核对 DOI、规范化引用、追溯出版者落地页或批量研究元数据。
- 它不等同于全文主机；DOI 能否访问、文章能否下载和许可信息是否完整，都应在出版者或原始存储库确认。

## 我的判断

- 做可靠引用与出版物标识核验不可替代；不要把 DOI 解析成功误读为开放全文。
