# 全国翻译专业资格（水平）考试 CATTI

[官方网站](https://www.catti.cn/)

## 它是什么

翻译、口译和笔译资格考试官方信息入口；报名通常跳转中国人事考试网或省级人事考试网。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
