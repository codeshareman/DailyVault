# 中国通信工业协会电子竞技分会

[官方网站](https://www.chinaesa.org.cn/index.aspx)

## 它是什么

中国通信工业协会电子竞技分会官网。页面原文所称“中国电子企业协会”与此名称并不一致，应以证书上的发证主体为准。

## 使用提醒

- 报名条件、开放时间、收费和证书效力以发证主体的当年度公告为准。
- 不要把协会证书、培训合格证明或岗位能力证书自动当作国家职业资格、准入资格或人社职业技能等级证书。
- 涉及个人证件和缴费时，应从官方主体网站反向核验报名机构。
