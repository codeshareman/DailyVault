# 淘宝

[官方网站](https://www.taobao.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web / App |
| 内容 | 商品、服务套餐、评价与交易信息 |
| 浏览方式 | 搜索关键词并进入商品详情 |
| 来源 | `url` |

## 它是什么

阿里巴巴旗下的综合网络购物平台。

## 为什么值得收藏

- 可比较办公服务、表格定制、数据处理等服务的套餐、修改次数和交付格式。

## 适合什么时候使用

- 区分软件成品与代办服务，研究服务标准化程度时。

## 使用限制

- 具体商品、评论和成交信息可能需要登录；商品存在不等于稳定成交或工具需求。
