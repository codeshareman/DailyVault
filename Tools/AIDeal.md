## 它是什么

AIDeal 自述为面向中文用户的 AI 订阅比价平台，汇集不同商户的账号、会员和 API 中转报价，并提供库存与交易避坑信息。它是第三方报价与渠道观察入口，不是 ChatGPT、Claude 等服务的官方订阅页。

## 为什么值得收藏

- 集中查看不同商户和交付方式，作为比较 AI 服务获取成本的起点。
- 保留 Claude 分类、销量优先的快捷入口，便于继续本次订阅渠道比较。
- 除价格外，也提供库存、采集字段和曝光入口，方便进一步核查信息时效与交易风险。

## 适合什么时候使用

- 寻找 AI 订阅或 API 中转的候选渠道时。
- 对比同一产品的交付方式、使用期限、额度与售后条件时。
- 与 [[AI 订阅价格雷达]] 交叉查看公开报价，再回到服务官方规则及商户条款核验时。

## 使用限制

- 本次读取确认了网站说明、筛选项与排序项；报价表仍显示“正在加载报价数据”，未核实具体商户、价格、库存或销量，也未验证曝光案例。
- 原链接保留 `category=Claude` 与 `sort=sales_desc` 参数；本次未验证动态页面最终筛选结果。
- 销量排序不等于交易真实性或可靠性背书；网站曝光内容也需要核对原始证据。
- 比价时需区分账号、会员和 API 中转，以及独享／共享、期限、模型权限、实际额度、限速和退款条件，不能只比较标价。
- 第三方渠道可能涉及账户共享、账号转让、跨区付款等限制；购买前核对服务官方条款、账号控制权和数据隐私风险。
- 本卡只收藏公开入口，不保存账号、密码、验证码、支付信息或私密交易链接。
