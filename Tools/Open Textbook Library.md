# Open Textbook Library｜开放教材发现与评审目录

[官方网站](https://open.umn.edu/opentextbooks/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放教材发现索引 |
| 内容 | 开放教材、同行评审与采用信息 |
| 获取方式 | 从教材条目进入出版者或托管方提供的版本 |

## 它是什么

Open Textbook Library 汇集开放教材，并提供发现、评审和采用参考，帮助教师与学习者筛选教材。

## 适合什么时候使用

- 为课程按学科与评价寻找开放教材时。
- 在采用前比较教材的内容、审阅和版本来源时。

## 下载与授权限制

- 它是发现与评价目录，并非每本教材的统一文件主机；实际下载或在线阅读由条目链接的来源决定。
- 开放教材的许可、格式和更新状态均需在具体教材页核对。

## 我的判断

- 适合“找教材并判断是否适合课程”的第一站；最终应以原始托管页的版本与许可为准。
