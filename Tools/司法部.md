# 司法部

[官方网站](https://www.moj.gov.cn/)

## 它是什么

国家统一法律职业资格考试公告、报名、缴费、准考证和成绩服务的司法部官方入口。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
