# Freelancer 任务列表

[官方网站](https://www.freelancer.com/jobs/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 自由职业任务、预算、时长、技能与筛选条件 |
| 浏览方式 | 按技能、预算、时长和项目类型筛选 |
| 来源 | `url` |

## 它是什么

自由职业项目与任务发布平台的公开列表。

## 为什么值得收藏

- 可直接观察买方如何描述数据处理、Excel、脚本和系统集成的交付结果。

## 适合什么时候使用

- 研究买方需求、任务边界与预算意向时。

## 使用限制

- 预算是意向，竞标价不是成交价；任务列表不能单独证明复发或付款完成。
