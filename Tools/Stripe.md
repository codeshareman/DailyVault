# 评估和接入产品支付能力

[Stripe](https://stripe.com/zh-us)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web、API、SDK |
| 内容 | 支付、计费、平台资金流转与金融工具 |
| 使用方式 | 产品商业化设计和支付流程实现 |
| 定价 | 按产品、地区和交易条件计费 |

## 它是什么

Stripe 提供线上与线下支付、计费和平台金融基础设施，并通过 API 与 SDK 接入产品。

## 为什么值得收藏

- 将支付、订阅计费和平台结算放在同一官方入口，适合实际商业化项目复用。

## 适合什么时候使用

- 规划产品收费模式、订阅、国际支付或平台分账时。

## 使用限制

- 地区可用性、合规、费用、税务、结算和账户条件必须按实际主体核对。
- 工具卡只保留公开产品入口，不保存控制台、客户或交易深链。
