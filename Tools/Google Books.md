# Google Books｜图书发现与预览目录

[官方网站](https://books.google.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 发现索引与预览目录 |
| 内容 | 图书检索、预览及部分在线阅读 |
| 获取方式 | 从图书页查看预览范围、购买链接或已授权阅读选项 |

## 它是什么

Google Books 是用于查找、预览和在线阅读图书的服务；官方页面明确将其定位为“Find, Preview, and Read Books Online”。

## 适合什么时候使用

- 通过题名、作者、关键词或书内片段定位图书时。
- 在借阅、购买或查找开放版本前确认版本与目录信息时。

## 下载与授权限制

- 它主要是发现与预览服务，预览、全文阅读和外部获取选项由具体图书的权利与出版方设置决定。
- 不应把可搜索、可预览或显示片段误当作可下载或可复制的授权。

## 我的判断

- 很适合书目核对和内容初筛；找到目标后应转向权利明确的出版社、图书馆或开放获取主机。
