# 在线机器翻译服务

[Google Translate](https://translate.google.com/?hl=zh-CN&sl=auto&tl=zh-CN&op=translate)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 词语、短语和网页翻译 |
| 浏览方式 | 选择语言后输入或粘贴文本 |

## 它是什么

Google Translate 是 Google 提供的在线机器翻译服务。

## 为什么值得收藏

- 可快速理解外语网页、短文本和术语。

## 适合什么时候使用

- 需要即时阅读或初步翻译多语言内容时。

## 使用限制

- 机器翻译不保证术语、语境和法律或专业文本的准确性。
