# 代码托管与协作开发平台

[GitHub](https://github.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 代码仓库、议题、代码评审、自动化与开发者协作 |
| 浏览方式 | 浏览公开仓库、文档和项目主页 |

## 它是什么

GitHub 是用于托管代码、协作开发和维护开源项目的平台。

## 为什么值得收藏

- 作为开源代码、项目文档和开发协作的公共入口。

## 适合什么时候使用

- 查阅项目源码、发布记录或维护讨论时。

## 使用限制

- 私有仓库与组织资源需要相应授权。
