# Unpaywall｜开放论文版本发现服务

[官方网站](https://unpaywall.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放获取位置发现与元数据服务 |
| 内容 | 学术文章的 OA 位置、链接和相关元数据 |
| 获取方式 | 通过结果链接访问机构库、预印本库或出版者页面 |

## 它是什么

Unpaywall 聚合学术文章的开放获取位置，帮助读者发现可合法访问的公开版本。

## 使用与授权

- 适合在已知 DOI 或论文题名后寻找作者存档、机构库或开放发表版本。
- Unpaywall 不等同于全文主机；点击到的文件能否下载和如何使用，必须以原始来源的权限与许可为准。

## 我的判断

- 是“已知论文、寻找合规开放版本”的高效工具；优先选择清晰标注许可的原始存储库链接。
