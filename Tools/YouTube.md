# 视频与音乐平台

[YouTube](https://www.youtube.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 视频、音乐、频道和直播 |
| 浏览方式 | 搜索、订阅和推荐流浏览 |

## 它是什么

YouTube 是用于观看、发布和分享视频及音乐内容的平台。

## 为什么值得收藏

- 是课程、产品演示、技术讲解和公开发布视频的常用入口。

## 适合什么时候使用

- 查找视频教程、演讲或产品演示时。

## 使用限制

- 推荐与可用内容会随地区、账号状态和版权政策变化。
