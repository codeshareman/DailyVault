# Open Book Publishers｜开放获取学术出版社

[官方网站](https://www.openbookpublishers.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 出版社主机与潜在直接下载来源 |
| 内容 | 开放获取学术图书及出版信息 |
| 获取方式 | 由图书页面提供阅读、购买或开放版本入口 |

## 它是什么

Open Book Publishers 是独立学术出版社，其官网集中提供出版图书、作者与可用版本的信息。

## 适合什么时候使用

- 查找该社出版的开放获取学术书或正式出版信息时。
- 需要从出版者源头确认版本、作者信息和许可时。

## 下载与授权限制

- 不是每种格式或每个版本都必然免费；开放版本、实体书和增值格式的可得性以图书页为准。
- 即使某书可免费阅读或下载，也须遵守该书列出的许可、署名与使用条件。

## 我的判断

- 出版者直达页适合确认 OA 学术书的权威版本；不要假定同一本书的所有格式具有相同权限。
