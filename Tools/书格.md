# 书格｜古籍善本与书画数字资源

[官方网站](https://www.shuge.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 潜在直接下载主机与资源导览 |
| 内容 | 精选古籍善本、字画及其数字化资料 |
| 获取方式 | 在资源页查看在线图像、下载链接或外部来源说明 |

## 它是什么

书格将自身描述为自由开放的数字图书馆，开放式分享、介绍与推荐有价值的古籍善本、字画，并侧重公共版权领域的数字资源。

## 适合什么时候使用

- 查找高质量古籍、书画影像的阅读与研究线索时。
- 需要从资源页追溯馆藏机构或原始数字化来源时。

## 下载与授权限制

- 站内部分资源页会给出文件或外部链接，但下载与使用范围必须以具体资源页、来源馆和权利说明为准。
- 展示、链接或站内的 CC BY 标识不自动改变原始作品影像、题跋或第三方文件的权利状态。

## 我的判断

- 是中文古籍与书画的高质量发现入口；应把每个资源的来源、版本和许可视为独立核验项。
