# BOSS 直聘

[官方网站](https://www.zhipin.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web / App |
| 内容 | 岗位、职责、技能和招聘沟通入口 |
| 浏览方式 | 按职业、行业和关键词检索岗位 |
| 来源 | `url` |

## 它是什么

面向中文求职与招聘的岗位信息平台。

## 为什么值得收藏

- 岗位职责能暴露电商运营、销售助理、薪酬绩效等角色的重复工作与工具栈。

## 适合什么时候使用

- 将职位中的职责拆成输入、判断和输出，寻找可辅助的窄环节时。

## 使用限制

- 招聘预算不能直接换算成软件预算；岗位中的工作也未必适合自动化。
