# 全国大学英语四、六级考试（CET）

[官方网站](https://cet.neea.edu.cn/)

## 它是什么

全国大学英语四、六级考试官方信息入口；具体报名通常由学校考点组织。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
