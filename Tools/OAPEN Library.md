# OAPEN Library｜开放获取学术图书存储库

[官方网站](https://library.oapen.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 潜在直接下载主机与开放图书存储库 |
| 内容 | 开放获取学术图书、书目与条目文件 |
| 获取方式 | 从具体条目查看可用文件与许可信息 |

## 它是什么

OAPEN Library 是一个面向开放获取图书的在线图书馆，提供学术书籍的书目记录、发现功能和条目级访问。

## 适合什么时候使用

- 寻找人文社会科学等领域的开放获取学术书时。
- 需要取得出版社或存储库提供的正式 OA 版本时。

## 下载与授权限制

- 多数条目可提供文件访问，但“可访问”与具体的下载格式、许可和再利用范围仍以条目页为准。
- 请遵守每本书附带的版权、Creative Commons 或出版者许可说明。

## 我的判断

- 是寻找正式开放获取学术书的重要主机；优先保存条目页与许可页，而不只保存文件副本。
