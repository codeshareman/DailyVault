# DOAJ｜开放获取期刊目录

[官方网站](https://doaj.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放获取期刊与文章发现索引 |
| 内容 | OA 期刊、文章元数据和外部全文链接 |
| 获取方式 | 检索后前往期刊或文章的原始出版页面 |

## 它是什么

DOAJ（Directory of Open Access Journals）是开放获取期刊目录，帮助用户发现符合其收录标准的 OA 期刊及其文章。

## 使用与授权

- 适合筛选 OA 期刊、寻找文章公开版本或核对期刊收录状态。
- DOAJ 是索引，通常不托管文章文件；全文下载、许可和数据使用条件以出版者页面及文章声明为准。

## 我的判断

- 适合做合规 OA 期刊发现；不要因期刊被收录而省略对单篇文章许可的核对。
