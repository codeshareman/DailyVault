# 比较职级与薪酬数据

[Levels.fyi](https://www.levels.fyi/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 公司、职位、职级、地区与薪酬数据 |
| 使用方式 | 求职或谈薪前做外部交叉核对 |
| 定价 | 公开数据与付费服务并存 |

## 它是什么

Levels.fyi 汇集不同公司、职位、职级和地区的薪酬数据，并提供职业与 offer 相关工具。

## 为什么值得收藏

- 可为职级映射和薪酬区间提供外部参照，避免只依据单一招聘方信息。

## 适合什么时候使用

- 比较 offer、准备谈薪或理解不同公司的职级体系时。

## 使用限制

- 数据受自报样本、地区、币种、岗位口径和时间影响。
- 不能把单条记录或平台区间直接视为个人市场价值或承诺薪酬。
