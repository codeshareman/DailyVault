# 将邮件订阅转换为 Atom feed

[Kill the Newsletter!](https://kill-the-newsletter.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 邮件订阅转换为 Atom feed |
| 浏览方式 | 创建 feed 后获得专用邮箱和 Atom feed，在 RSS 阅读器中订阅 |
| 定价 | 官网未标价；提供赞助入口 |
| 创建者 | Leandro Facchinetti |

## 它是什么

Kill the Newsletter! 为每个 feed 提供专用邮箱和对应的 Atom feed。使用该邮箱订阅邮件通讯后，收到的邮件会转换为 feed 条目，可在 RSS 阅读器中阅读。

## 为什么值得收藏

- 将邮件通讯集中到 RSS 阅读器，避免订阅内容占用主邮箱。
- 不必向通讯发布者提供日常使用的邮箱地址。
- 官网说明服务本身不跟踪用户。

## 适合什么时候使用

- 希望用 RSS 阅读器集中阅读邮件订阅时。
- 不希望将邮件通讯直接发送到主邮箱时。
- 需要为不同订阅创建独立接收地址时。

## 使用限制

- 有些通讯发布者会拦截该服务生成的邮箱地址。
- 需要回复确认邮件的订阅流程不受支持；官网建议联系发布者人工验证，或尝试从常用邮箱转发。
- feed 链接包含接收邮箱的标识，不应分享给他人。
- 为控制 feed 体积，旧条目可能被删除。
