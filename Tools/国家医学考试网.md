# 国家医学考试网

[官方网站](https://www.nmec.org.cn/)

## 它是什么

医师资格考试报名及考试服务入口，地方审核和考点安排以卫生健康部门公告为准。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
