# Shopify Community

[官方网站](https://community.shopify.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 商家问题、开发者支持与应用讨论 |
| 浏览方式 | 按分类、关键词和主题浏览 |
| 来源 | `url` |

## 它是什么

Shopify 商家与开发者的社区支持入口。

## 为什么值得收藏

- 可将商家实际问题与 Shopify App Store 的功能、价格和评价配对。

## 适合什么时候使用

- 研究订单、库存、报表和应用连接的未覆盖步骤时。

## 使用限制

- 个别主题是否解决需看回复和日期；社区发言不等于购买意愿。
