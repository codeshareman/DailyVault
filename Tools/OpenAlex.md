# OpenAlex｜开放学术元数据目录

[官方网站](https://openalex.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放学术元数据与发现服务 |
| 内容 | 作品、作者、机构、来源和引文关系 |
| 获取方式 | 使用网站、API 或数据集查询元数据和外部链接 |

## 它是什么

OpenAlex 是开放的全球研究系统目录，组织并提供学术作品、研究主体和关联关系的元数据。

## 使用与授权

- 适合文献计量、机构研究画像、引文网络和开放版本线索发现。
- 它主要提供元数据而不是论文全文；外部全文链接能否下载、再利用或批量处理取决于原始主机和条目许可。

## 我的判断

- 对结构化研究发现很强；应把 OpenAlex 数据和论文全文的授权分别核验。
