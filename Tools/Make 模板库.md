# Make 模板库

[官方网站](https://www.make.com/en/templates)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 预建自动化场景、应用连接与数据映射 |
| 浏览方式 | 按任务、应用和场景浏览模板 |
| 来源 | `url` |

## 它是什么

Make 的自动化工作流模板目录。

## 为什么值得收藏

- 可观察一个任务的触发—处理—结果结构，以及仍需手工收尾的部分。

## 适合什么时候使用

- 研究业务流程自动化和应用连接的配置难点时。

## 使用限制

- 模板是方案供给；模板免费不代表运行没有费用，也不代表真实采用或付费需求。
