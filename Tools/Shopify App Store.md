# Shopify App Store

[官方网站](https://apps.shopify.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 电商应用、功能、价格、评价与集成 |
| 浏览方式 | 按订单、库存、报表等业务方向检索 |
| 来源 | `url` |

## 它是什么

Shopify 面向商家的应用分发与发现平台。

## 为什么值得收藏

- 可将应用功能、价格与评论和商户实际流程问题配对观察。

## 适合什么时候使用

- 研究电商经营中已经被产品化、仍需手工处理或存在集成缺口的步骤时。

## 使用限制

- 有付费方案不代表每位评论者都付费；评论、安装和排名都不是单独的成交证据。
