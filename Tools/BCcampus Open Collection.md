# BCcampus Open Collection｜开放教育资源集合

[官方网站](https://open.bccampus.ca/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放教育资源主机与发现入口 |
| 内容 | 高等教育开放教材与其他 OER |
| 获取方式 | 在资源页查看在线版本、文件和许可 |

## 它是什么

BCcampus Open Collection 汇集 BCcampus 推动的开放教育资源和开放教材。

## 使用与授权

- 适合按课程主题寻找可采用或可改编的 OER；先从资源页确认版本与教学用途。
- 部分资源可直接取得文件，但下载和再利用取决于单项许可；不得以集合名称推断所有资料具相同权限。

## 我的判断

- 适合作为高等教育 OER 的权威发现来源；课程采用前逐项核对许可与更新日期。
