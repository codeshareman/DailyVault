# 中国卫生人才网

[官方网站](https://www.21wecan.com/)

## 它是什么

护士执业资格、卫生专业技术资格等卫生人才考试服务入口，具体审核按考区执行。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
