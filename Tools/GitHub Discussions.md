# GitHub Discussions

[官方网站](https://docs.github.com/en/discussions/collaborating-with-your-community-using-discussions/about-discussions)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | GitHub Discussions 的社区问答、信息分享与讨论说明 |
| 浏览方式 | 按主题阅读官方文档 |
| 来源 | `url` |

## 它是什么

GitHub 官方提供的 Discussions 使用文档。

## 为什么值得收藏

- 适合核对 Discussions 作为项目社区输入渠道的用途。

## 适合什么时候使用

- 研究开源项目中的问题背景、经验分享和功能讨论时。

## 使用限制

- 文档介绍产品能力；具体项目是否开放 Discussions 及内容质量需逐仓库核实。
