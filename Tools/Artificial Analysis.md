## 它是什么

Artificial Analysis 是模型评测与分析服务。它把模型能力、任务成本、输出速度、首字延迟、上下文和服务端点属性放在同一比较面板中，并提供方法说明和数据 API。平台将自己定位为独立评测机构；使用时仍需审阅其测试方法和指标权重。

## 为什么值得收藏

- 在模型选型初期快速形成可比较的候选集，避免只看厂商宣传或单一综合分数。
- 同时呈现能力、成本与实际端点性能，适合发现“模型强但服务慢”或“单价低但任务成本高”等差异。
- 方法论和 API 为复核指标含义、追踪数据与自动化分析提供入口。
- 比公益榜单或一次性截图更稳定，也不会把某一时刻名次写成长期事实。

## 适合什么时候使用

- 为具体应用筛选模型和服务端点时。
- 比较模型能力、任务成本、吞吐与延迟的取舍时。
- 在正式压测前缩小候选范围时。
- 需要把公开比较数据接入内部评估流程时。

## 使用限制

- 综合分数、任务成本和排序取决于平台选择的工作负载、权重与测试提示。
- 速度和延迟是特定端点、提示长度和测量时点的快照，不能替代自身业务压测。
- 平台的“独立”属于其自我定位，不能代替对利益关联、测试设计和数据更新日期的审阅。
- 最终采购、上线和可靠性判断仍应回到供应商条款、实际账单与真实任务验证。
