# 将个人知识库变成可持续使用的学习环境

[DeepTutor](https://deeptutor.info/zh-cn/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web、本地应用、CLI |
| 内容 | 个性化学习、知识库、记忆、智能体协作与 Markdown 写作 |
| 浏览方式 | 官网与本地 Web 工作区；可通过 CLI 初始化和启动 |

## 它是什么

DeepTutor 是一个开源的 agent-native 个性化学习伴侣。主页、伙伴、我的智能体、协同写作、交互式书本、学习空间、记忆和知识中心共享同一份运行时上下文；在不同界面间切换时，学习任务、资料与上下文不会被割裂。

它可将本地 Claude Code 或 Codex 接入工作区，并提供知识库检索、三层可审计记忆、选区级 Markdown AI 编辑，以及将笔记和知识库组织为交互式书本的能力。

## 为什么值得收藏

- 将资料检索、长期记忆、写作与对话放入同一学习工作区，减少工具之间的上下文断裂。
- 可连接本地编程代理，适合把代码学习、问题探索和知识沉淀结合起来。
- 使用版本化知识中心与可审计记忆，便于追溯回答所依据的资料与个性化信息。
- Apache 2.0 开源，既可本地试用，也可研究其学习型 agent 的实现方式。

## 适合什么时候使用

- 希望围绕个人笔记和资料库建立长期学习工作流时。
- 需要在 Markdown 写作过程中引用知识库或网络资料时。
- 想把 AI 编程代理、学习对话和个人知识管理放在同一环境中时。
- 需要管理可复用的学习技能、伙伴人格、笔记或题目资产时。

## 使用限制

- 它是完整的本地学习工作区，不是轻量的单次问答工具；仅需临时聊天或简单记笔记时，部署和配置成本未必合算。
- 是否能稳定接入 Claude Code、Codex 或其他本地工具，取决于本机环境与相应配置。
- 官网列出 PyPI、Docker、源码和 CLI 四种安装方式；具体安装与运行要求应以[官方文档](https://docs.deeptutor.info/zh-cn/get-started/)为准。
