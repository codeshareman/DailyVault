# 中华古籍智慧化服务平台｜古籍数字资源服务

[官方网站](https://guji.nlc.cn/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 机构数字资源与发现平台 |
| 内容 | 古籍数字资源的检索、浏览与服务入口 |
| 获取方式 | 按资源条目的在线浏览、下载或访问提示使用 |

## 它是什么

中华古籍智慧化服务平台是面向古籍数字资源的服务平台，提供古籍资料的发现与在线使用入口。

## 适合什么时候使用

- 查找古籍题名、版本或数字化浏览线索时。
- 需要优先核对国家级机构服务中某种古籍的可访问范围时。

## 下载与授权限制

- 平台是机构数字资源服务，不应预设所有条目可直接下载；图像、全文、下载和登录要求以条目提示为准。
- 古籍原件、数字化影像及其衍生文件的使用许可可能不同，并受条目权利说明和所在地规则限制。

## 我的判断

- 适合做古籍权威来源核验与资源发现；只有条目明确开放时才应将其当作下载来源。
