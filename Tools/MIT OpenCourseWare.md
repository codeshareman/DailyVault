# MIT OpenCourseWare｜MIT 公开课程资料

[官方网站](https://ocw.mit.edu/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放课程材料主机 |
| 内容 | 课程页面、讲义、作业与部分媒体资源 |
| 获取方式 | 通过具体课程页阅读、观看或获取所提供材料 |

## 它是什么

MIT OpenCourseWare 免费公开麻省理工学院课程的教学材料，供全球学习者和教师使用。

## 适合什么时候使用

- 按课程主题系统自学或参考课程设计时。
- 查找 MIT 课程大纲、讲义、作业和公开媒体材料时。

## 下载与授权限制

- 并非每门课都拥有相同材料或文件下载选项，视频、课件和外链资源以课程页为准。
- 课程材料通常有明确许可，但第三方内容、商标和外部链接可能另受限制；应查看页面版权说明。

## 我的判断

- 适合课程式学习与教学设计参照；它不是学位项目，也不应将公开材料误当作授课、认证或全部课程资源。
