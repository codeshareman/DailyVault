# 查询中国官方统计指标

[国家数据](https://data.stats.gov.cn/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 宏观、行业、地区与统计指标 |
| 使用方式 | 有明确研究问题时查询原始统计口径 |
| 定价 | 公开访问 |

## 它是什么

国家数据是国家统计局的统计数据查询入口，可用于定位中国宏观、行业和地区指标。

## 为什么值得收藏

- 比二手报告更接近原始统计来源，适合为市场与业务判断建立可追溯证据。

## 适合什么时候使用

- 验证市场规模、宏观趋势或地区差异时。

## 使用限制

- 必须核对指标定义、统计范围、发布日期、修订说明和数据滞后。
- 单一指标不能直接推出商业结论，需要结合问题、口径和其他证据解释。
