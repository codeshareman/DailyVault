# 生成式 AI 对话服务

[ChatGPT](https://chatgpt.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 写作、分析、规划、问答和生成式对话 |
| 浏览方式 | 通过对话界面输入任务与上下文 |

## 它是什么

ChatGPT 是 OpenAI 提供的生成式 AI 对话服务。

## 为什么值得收藏

- 可作为日常写作、研究辅助和任务拆解的交互入口。

## 适合什么时候使用

- 需要快速生成草稿、梳理思路或分析文本时。

## 使用限制

- 输出可能不准确；敏感信息、关键决策和事实结论应独立核验。
