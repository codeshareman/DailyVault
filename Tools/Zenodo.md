# Zenodo｜开放科研成果存储库

[官方网站](https://zenodo.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 研究成果存储库与潜在直接下载主机 |
| 内容 | 数据、软件、论文、报告和其他科研输出 |
| 获取方式 | 从记录页查看文件、版本、访问级别和许可 |

## 它是什么

Zenodo 是开放科研存储库，供研究者发布和保存数据、软件、论文及其他研究成果，并为记录提供持久标识符。

## 使用与授权

- 适合获得论文补充数据、可复现代码、数据集或带 DOI 的研究归档版本。
- 记录可公开、受限或受控访问；即使能下载，也须遵循该记录的许可证、引用要求和敏感数据限制。

## 我的判断

- 对可复现研究和正式归档很实用；务必记录版本号、DOI 与许可证，避免把同名文件当作同一版本。
