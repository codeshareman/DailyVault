# 注册会计师全国统一考试网上报名

[官方网站](https://cpaexam.cicpa.org.cn/)

## 它是什么

中国注册会计师协会组织的注册会计师全国统一考试官方网报系统。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
