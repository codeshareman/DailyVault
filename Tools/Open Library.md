# Open Library｜开放图书目录与借阅入口

[官方网站](https://openlibrary.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 开放书目目录与受控借阅入口 |
| 内容 | 可编辑书目记录及部分数字图书访问选项 |
| 获取方式 | 按书目页显示的公开阅读、借阅或外部链接使用 |

## 它是什么

Open Library 是开放、可编辑的图书目录，提供书目信息，并为部分数字图书提供阅读或借阅入口。

## 使用与授权

- 适合核对版本、ISBN、作者作品关系，或查找可借阅的数字书线索。
- 目录本身不表示全文可下载；数字书可能受借阅、账户、排队或权利限制，不能绕过访问控制。

## 我的判断

- 书目探索和版本辨识很有用；把其数字访问选项视为逐书受控服务，而非通用下载来源。
