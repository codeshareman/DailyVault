# Pressbooks Directory｜Pressbooks 图书发现目录

[官方网站](https://pressbooks.directory/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 图书发现目录 |
| 内容 | 用 Pressbooks 制作的开放教材与其他图书条目 |
| 获取方式 | 通过条目进入对应图书的原始页面 |

## 它是什么

Pressbooks Directory 是 Pressbooks 图书的发现目录，方便按主题、机构或标题查找公开图书。

## 使用与授权

- 适合发现 OER 或定位使用 Pressbooks 发布的某一本书。
- 它不是统一下载主机；在线阅读、导出格式和许可由每本书及其发布机构决定。

## 我的判断

- 检索效率高，适合做教材发现；最后必须在目标图书页面确认文件与授权。
