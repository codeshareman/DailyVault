# HathiTrust Digital Library｜学术馆藏数字图书馆

[官方网站](https://www.hathitrust.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 图书馆访问与馆藏发现平台 |
| 内容 | 参与学术与研究机构贡献的数字化馆藏与书目记录 |
| 获取方式 | 依条目显示的全文、检索或机构访问状态使用 |

## 它是什么

HathiTrust Digital Library 汇集成员机构数字化馆藏，并按作品的权利与访问状态提供不同程度的阅读、检索和机构功能。

## 适合什么时候使用

- 核对学术图书馆是否已数字化某种图书时。
- 查找可全文阅读的公共领域馆藏，或定位仍受限的版本记录时。

## 下载与授权限制

- 这是图书馆访问平台，不是所有馆藏的直接下载站；全文、下载和账户功能均可能因条目、成员资格与地域而异。
- 仅在条目明确开放的范围内使用，不得以搜索可见性推断全文或再利用授权。

## 我的判断

- 对馆藏发现和公共领域版本核验很有价值；先看条目的访问标签，再决定是否能读或下载。
