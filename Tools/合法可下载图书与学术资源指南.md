# 合法可下载图书与学术资源指南

> **用途**：用官方入口寻找可合法获取的图书、教材、论文与技术报告。这里的“可下载”是**优先检查官方条目是否提供合法文件**，不是“任何书都能下载”的承诺。
>
> **边界**：每本书、每篇文章、每个扫描件的开放状态、格式、许可、地域和机构访问条件都可能不同；即使同一平台的不同条目也可能分别是直接下载、在线阅读、局部预览、受控借阅或仅提供书目信息。最终以**具体条目的官方页面和许可说明**为准。

## 一页速决

```text
已知题名、作者、ISBN 或 DOI？
├─ 是 → 先到对应“直接宿主”查具体条目与许可
│       ├─ 出现官方 Download / PDF / EPUB / Full text，且许可或权利状态允许
│       │   └─ 记录条目页、格式、许可、核验日期后下载
│       ├─ 只有 Preview / Read online / Snippet
│       │   └─ 视为预览；转向 DOI、ISBN、馆藏或开放版本检索，不导出受限内容
│       └─ 只有 Borrow / Login / Request / 机构访问
│           └─ 视为受控访问；遵守借阅、账户和机构条款，不把它当永久下载
└─ 否 → 按资料类型开始
        ├─ 公版书、古籍、扫描本 → Gutenberg、Standard Ebooks、书格、古籍平台等
        ├─ 开放教材／开放图书 → OAPEN、OpenStax、大学出版社与教材目录
        ├─ 论文／预印本／报告 → arXiv、PMC、Zenodo、World Bank、NASA NTRS 等
        └─ 只需找出处或合法版本 → Google Scholar、Unpaywall、Crossref、WorldCat 等

任何一步的权利或访问条件不清楚 → 只交付官方条目链接和“不确定”说明，不交付文件副本。
```

## 先读：访问角色不是同义词

| 角色 | 本指南中的含义 | 是否可直接当作“可下载” |
| --- | --- | --- |
| **直接宿主** | 官方站点在具体条目页自行托管文件或明确给出文件入口。 | 否；仍须逐条核对格式、许可和地区条件。 |
| **发现索引** | 检索、目录、知识图谱或书目信息服务，用于定位原始来源。 | 否；它可能只有链接、摘要或元数据。 |
| **预览服务** | 展示封面、片段、有限页或部分内容。 | 否；预览不等于授权下载。 |
| **受控借阅／馆藏访问** | 账户、机构、队列、馆内网络、咨询或时间限制下的访问。 | 否；不得绕过、提取或再分发。 |
| **元数据服务** | 提供 DOI、ISBN、引文、馆藏定位或开放版本线索。 | 否；它本身通常不托管全文。 |

**证据约定**：下表每个资源名称均链接到其官方入口；表内只描述该入口在官方页面所表明的资源类别或使用角色。文件、许可和权限均以最终条目页为准。

## 标准操作：从“找到”到“可交付”

1. **锁定条目**：优先使用题名、作者、出版社、出版年、ISBN、DOI、arXiv ID 或报告号，而不是模糊关键词。
2. **从官方入口进入具体记录**：不要把搜索引擎缓存、论坛转链、镜像站或网盘结果当作来源。
3. **识别访问层**：只有官方条目中明确的下载文件或开放全文入口，才进入“可下载”候选；`Preview`、`Snippet`、`Borrow`、`Request`、`Login`、`馆内访问` 分别记录为预览或受控访问。
4. **逐条核对权利**：查看该条目的许可（例如 CC 条款）、版权／公版声明、使用条款、地域和机构限制；平台首页的“开放”表述不足以替代条目许可。
5. **确认版本与格式**：记录下载的是哪个版本（预印本、作者稿、正式版、扫描版、修订版），以及实际提供的 PDF、EPUB、HTML、TXT、图像或数据格式。
6. **保留可复核证据**：至少保存官方条目 URL、资源名称、版本／标识符、许可或权限说明的位置、访问角色和核验日期。
7. **只交付可授权的内容**：交付优先为官方链接与获取说明；除非条目许可明确允许，否则不重新上传、打包、转存或转授文件。
8. **引用来源而非猜测来源**：论文用 DOI、arXiv ID、PMCID 等；图书用版本、ISBN 和出版方页；技术报告用报告号和记录页。

## 下载与权利核验清单

在点击下载、保存文件或向他人推荐前，逐项确认：

- [ ] 当前页面属于官方域名、出版方、机构库或明确授权的合作服务，而非不明镜像、网盘或转载页。
- [ ] 已打开**具体条目页**，不是仅看搜索结果、目录页、预览页或外部摘要。
- [ ] 条目页明确显示文件、开放全文、可用格式或适用的获取方式；若只显示借阅、登录、请求或阅读器，则按受控访问处理。
- [ ] 已读到条目级的许可、版权、公版、再利用或服务条款；没有明确许可时，不假设可复制、改编或再分发。
- [ ] 已检查地域、账户、机构网络、并发、借期、打印／下载额度等限制（若有）。
- [ ] 已确认版本、作者、出版年、ISBN／DOI／报告号与所需内容一致，避免把预印本、节选或扫描残本当正式全本。
- [ ] 已记录官方 URL、核验日期和必要引文信息；可复核而不是只留一个文件名。
- [ ] 若用途是交付、教学、再发布或机器处理，已额外确认许可是否允许该用途，而不只确认“本人能打开”。

## 对外／客户交付模板

只交付经过上述核验的结果；未核验的项目使用“候选线索”措辞，不承诺下载。可直接复制：

```markdown
### 资源交付｜[题名／资源名]

- 官方条目：<https://example.org/record>
- 资源类型：[图书／教材／论文／预印本／技术报告／数据集]
- 访问角色：[直接宿主／发现索引／预览／受控借阅／元数据]
- 当前可见获取方式：[例如：官方 PDF；EPUB；仅在线阅读；仅预览；需馆藏／申请]
- 版本与标识符：[出版年、版本、ISBN／DOI／arXiv ID／报告号]
- 权利依据：[条目页显示的许可证、版权／公版说明或服务条款链接]
- 适用限制：[地域、机构登录、借阅期、不可再分发、版本差异等]
- 核验日期：[YYYY-MM-DD]
- 引用建议：[作者，题名，出版方／期刊，年份，永久标识符]

说明：本交付仅说明上述官方条目在核验日显示的获取方式；不保证其他版本、其他地区、其他账户或未来时间仍以相同方式开放。
```

## 明确禁止的来源与做法

本指南**不收录、不推荐、不交付**以下内容，也不以“学习”“研究”“已付费”“网上能找到”为理由例外：

- 盗版站、未经授权转载、P2P 索引、论坛附件、私人网盘、云盘分享、聚合下载站或来路不明的“全本”包。
- 绕过付费墙、登录、机构认证、并发限制、借阅期、DRM、阅读器限制、验证码、反爬或其他访问控制的工具、步骤、脚本或代操作。
- 共享／出售账户、机构凭证、借阅名额、下载配额、API 密钥或他人授权会话。
- 从受控借阅、受限阅读器或仅预览页面提取、拼接、OCR 后传播内容；也不将截图、缓存或临时文件伪装为公开下载。
- 将 Google Books、WorldCat、Crossref、ISBNdb、Google Scholar、OpenAlex、Unpaywall 等发现或元数据服务错误宣传为“免费图书下载站”。

如找不到合法的直接版本，正确交付是：提供官方出版方页、图书馆馆藏／馆际互借线索、合法购买或开放替代版本，而不是寻找绕过途径。

## 结论

以**官方条目 → 条目级访问方式 → 条目级权利说明**为唯一决策链。直接下载优先，但“能检索到”“能预览到”“能借到”都不是“获授权下载或再分发”；当条件不明确时，保守地交付官方链接和限制说明，胜过提供未经授权的文件。
