# 用结构化数据维护简历

[JSONCV Editor](https://jsoncv.reorx.com/editor/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | JSON 简历数据、编辑与预览 |
| 使用方式 | 分离简历内容与展示模板 |
| 定价 | 未知 |

## 它是什么

JSONCV Editor 是 jsoncv 项目的在线编辑器，用结构化数据维护简历内容，并提供对应的预览入口。

## 为什么值得收藏

- 结构化内容便于版本管理、复用和比较，不必维护多份相互漂移的文档。

## 适合什么时候使用

- 更新可版本化简历或尝试从同一份数据生成不同展示时。

## 使用限制

- 简历包含个人信息；使用前应确认浏览器存储、网络传输和导出行为。
- 模板输出仍需按职位人工校对，不能替代内容取舍和事实核验。
