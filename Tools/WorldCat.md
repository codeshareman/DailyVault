# WorldCat｜全球图书馆馆藏目录

[官方网站](https://search.worldcat.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 联合目录与馆藏发现服务 |
| 内容 | 图书、期刊和其他资料的书目与馆藏地点 |
| 获取方式 | 检索后联系本地或馆藏图书馆使用资料 |

## 它是什么

WorldCat 是图书馆馆藏发现服务，用于定位某种资料由哪些图书馆收藏。

## 使用与授权

- 适合确认版本、查找附近或可馆际获取的馆藏，并为借阅咨询提供依据。
- 它不是全文下载主机；有馆藏记录不代表可在线读、可借或可复制，访问由具体图书馆与条目决定。

## 我的判断

- 查实体书、稀见版本和图书馆可得性时很可靠；应在本地馆或持有馆页面落实访问条件。
