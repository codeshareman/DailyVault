[ModelScope 模型库](https://modelscope.cn/models)

## 它是什么

ModelScope 是模型与数据集 Hub，并提供版本化下载、SDK 和 CLI。它对中国模型生态、中文语音、计算机视觉、多模态与相关资源具有补充价值；这张卡将其定位为 Hugging Face 之外的区域与任务补充目录，而不是替代品。

## 为什么值得收藏

- 便于发现中文任务、中国模型生态和部分在国内更易访问的模型与数据集。
- 官方 SDK 与 CLI 支持搜索、下载、版本管理及程序化接入。
- 可与 Hugging Face 交叉核对模型版本、发布者、文件和生态支持。
- 它是持续维护的 Hub 与开发接口，不是临时公益推理入口。

## 适合什么时候使用

- 查找中文语音、视觉、多模态或中国模型生态资源时。
- 需要通过 SDK/CLI 下载和管理 ModelScope Hub 资源时。
- 某个模型在 Hugging Face 信息不足、访问不便或版本不同，需要交叉核对时。
- 需要定位模型关联的数据集、代码和发布组织时。

## 使用限制

- 与 Hugging Face 的模型发现能力存在重叠；没有中国模型生态或中文任务需求时，优先使用信息密度更高的单一入口。
- 需要逐模型核对许可证、来源、版本、下载门槛和运行要求。
- 部分资源可能要求登录 token、gated mode 或访问审批，不能把目录可见等同于无条件可用。
- 卡片只写 ModelScope Hub 可验证的产品边界，不推断未由一手资料确认的法定主体关系。
