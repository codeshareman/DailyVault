# Upwork 自动化任务

[官方网站](https://www.upwork.com/freelance-jobs/automation/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 自动化相关自由职业任务、结果要求和预算 |
| 浏览方式 | 按任务类别和关键词筛选 |
| 来源 | `url` |

## 它是什么

Upwork 的自动化自由职业任务入口。

## 为什么值得收藏

- 理论上可直接观察买方如何描述自动化结果、范围和预算。

## 适合什么时候使用

- 研究海外自动化外包需求时。

## 使用限制

- 本次抓取返回 HTTP 403，未核实当前任务列表；不得把入口页面当作已验证样本。
