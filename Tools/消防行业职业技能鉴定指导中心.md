# 消防行业职业技能鉴定指导中心

[官方网站](https://xfhyjd.119.gov.cn/)

## 它是什么

消防设施操作员等消防行业职业技能鉴定官方信息和报名入口，考点与批次由当地鉴定站执行。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
