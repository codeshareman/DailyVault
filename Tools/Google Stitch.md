# 用 AI 快速探索界面方案

[Google Stitch](https://stitch.withgoogle.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 移动端与 Web UI 生成、设计构思和原型探索 |
| 使用方式 | 在需求明确后快速生成多个方向并人工筛选 |
| 定价 | 未知 |

## 它是什么

Google Stitch 使用 AI 生成移动端和 Web 应用界面，目标是降低早期设计构思与方案探索成本。

## 为什么值得收藏

- 适合在正式设计前快速比较布局和视觉方向，而不是收藏大量 UI 灵感站。

## 适合什么时候使用

- 产品早期需要把需求转成可讨论的界面草案时。

## 使用限制

- 生成结果不是可直接交付的设计或生产代码，仍需人工审阅信息架构、交互、响应式、可访问性和实现质量。
- 产品功能与额度可能变化，应以当前页面和条款为准。
