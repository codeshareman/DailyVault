# 国家哲学社会科学文献中心｜哲学社会科学文献服务

[官方网站](https://www.ncpssd.cn/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 学术文献发现与访问服务 |
| 内容 | 中文期刊、外文期刊、集刊、古籍、外文图书等 |
| 获取方式 | 通过检索结果与条目显示的在线阅读或访问条件使用 |

## 它是什么

国家哲学社会科学文献中心由中国社会科学院牵头建设，面向哲学社会科学领域开展文献信息资源建设和服务，官方列出中文期刊、外文期刊、集刊、古籍与外文图书等文献类型。

## 适合什么时候使用

- 检索人文社会科学主题的期刊、古籍与相关书目信息时。
- 需要先确认一篇文献的馆藏、平台收录与可访问状态时。

## 下载与授权限制

- 该中心是文献服务平台；检索到条目不代表全部内容均可直接下载，登录、在线阅读和全文范围以条目状态为准。
- 文章与图书的版权、转载和数据使用条件可能不同，须遵循平台规则与单条文献权利说明。

## 我的判断

- 对中文人文社科资料发现很有用；把“被收录”和“获得全文下载授权”严格分开判断。
