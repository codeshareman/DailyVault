# arXiv｜开放预印本论文库

[官方网站](https://arxiv.org/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 角色 | 论文预印本主机与直接下载来源 |
| 内容 | 多学科研究预印本及其版本记录 |
| 获取方式 | 在论文页在线阅读或下载其提供的文件 |

## 它是什么

arXiv 是开放研究论文预印本库，覆盖物理、数学、计算机科学、统计等多个领域。

## 使用与授权

- 适合跟踪新近研究、获得作者公开版本或建立预印本引用线索。
- 可下载不表示所有论文均已同行评审或可任意再利用；论文版本、作者版权选择和单篇许可必须分别确认。

## 我的判断

- 研究追踪必备，但引用和实践决策应核对版本、同行评审状态和后续正式出版信息。
