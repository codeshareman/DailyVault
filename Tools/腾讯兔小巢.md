# 腾讯兔小巢

[官方网站](https://support.qq.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 软件反馈、意见、问题和产品回复 |
| 浏览方式 | 从具体软件的帮助或反馈入口进入 |
| 来源 | `url` |

## 它是什么

腾讯提供的用户意见反馈平台。

## 为什么值得收藏

- 可观察具体产品用户提交的功能意见和使用问题。

## 适合什么时候使用

- 研究某个目标软件的反馈、限制和用户原话时。

## 使用限制

- 首页不是全产品需求列表；应进入具体产品反馈空间。反馈不等于付款意愿。
