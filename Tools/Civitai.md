# 查找图像生成模型与创作资源

[Civitai](https://civitai.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | Stable Diffusion、Flux 模型、图像、工作流与社区资源 |
| 使用方式 | 按具体创作需求筛选并审阅资源 |
| 定价 | 公开资源、社区积分与付费功能并存 |

## 它是什么

Civitai 是生成式图像社区与资源目录，提供模型、图像和创作资源的发现与分享入口。它补充 Hugging Face 的通用模型目录，聚焦图像创作生态。

## 为什么值得收藏

- 将图像生成专用资源从通用模型 Hub 中分离，便于按视觉任务查找。

## 适合什么时候使用

- 需要寻找 Stable Diffusion、Flux 等图像模型或参考社区作品时。

## 使用限制

- 社区资源的来源、许可证、训练数据、内容安全和质量需要逐项核验。
- 下载模型仍需进行文件安全检查，并确认适用的商业和内容政策。
