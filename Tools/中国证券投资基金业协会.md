# 中国证券投资基金业协会

[官方网站](https://www.amac.org.cn/)

## 它是什么

基金从业人员资格考试及基金行业考试服务入口。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
