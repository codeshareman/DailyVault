# 全国大学英语四、六级考试报名网

[官方网站](https://cet-bm.neea.edu.cn/)

## 它是什么

CET笔试、口试资格审核、报名和缴费系统，报名时间以学校考点通知为准。

## 使用提醒

- 报名条件、开放时间、属地限制和收费标准以当年度官方公告为准。
- 不要通过代报名、保过或无法从官方页面反向核验的第三方链接缴费。
