# 新产品发现社区

[Product Hunt](https://www.producthunt.com/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | 新产品发布、榜单与社区讨论 |
| 浏览方式 | 浏览产品页、榜单和 Atom feed |

## 它是什么

Product Hunt 是一个发现、发布和讨论新产品的社区平台。

## 为什么值得收藏

- 适合跟踪产品发布、探索新工具和观察产品定位。

## 适合什么时候使用

- 调研同类产品或寻找新工具时。

## 使用限制

- 上榜与讨论热度反映社区活动，不等同于产品质量或长期可用性。
