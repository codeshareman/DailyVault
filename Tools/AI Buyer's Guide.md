# AI Buyer's Guide｜AI 产品订阅与兼容性比较

[官方网站](https://ai.dal.ao/)

## 基本信息

| 项目 | 信息 |
| --- | --- |
| 平台 | Web |
| 内容 | AI 产品的订阅价格范围、模型家族与模型覆盖、兼容目标、部分模型能力指标与数据更新时间 |
| 浏览方式 | 按产品目录筛选货币、月付／年付与排序，再进入产品详情或比较页 |
| 目录范围 | 首页显示 39 个产品、603 个模型与 28 个兼容目标；数量会随站点更新变化 |

## 它是什么

AI Buyer's Guide 是一个面向 AI 产品订阅选择的比较目录。其首页将产品的价格范围、可用模型、兼容目标和数据更新时间并列，并允许把候选产品放入比较视图。部分条目同时显示引用的 Artificial Analysis Intelligence Index 分数，但该分数不等同于产品本身的完整体验或可靠性。

## 为什么值得收藏

- 在订阅 AI 编程、对话或模型服务前，快速缩小产品、模型覆盖和兼容目标的候选范围。
- 将产品定价、可访问的模型和平台兼容性放在同一比较界面，便于先识别结构性差异。
- 提供更新时间，提醒使用者把目录数据当作有时效的观察记录，而非永久事实。

## 适合什么时候使用

- 选择 AI 编程工具、模型订阅或 Token 计划前进行初步筛选时。
- 比较候选服务可用模型、兼容生态和月付／年付价格结构时。
- 在打开各供应商官方定价页和条款前，建立待核验的产品清单时。

## 使用限制

- 价格范围、可用模型、地区版本、套餐权益和兼容性可能变化；必须以供应商结账页、模型列表和条款为准。
- 站点展示的能力分数来自其标注的数据来源与指定模型，不能推导为工具整体质量、稳定性、隐私性或对某项任务的表现。
- “兼容”需要进一步区分原生支持、API 支持、账户等级、地区可用性和实际工作流限制；目录计数不能替代集成测试。
- 不在本卡保存账户、API Key、订阅账单或私密购买链接。
